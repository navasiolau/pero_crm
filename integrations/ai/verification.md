# Проверка AI-комплекта №187

18.10.2026, `feature/187`, базовый staging `d918ab860ec5aab029c466a3b3c3b1ce06f0ec98`. Комплект в рабочем дереве; commit/deployment/установка пока не выполнялись.

MCP stdio, Python-помощник и навык используют общий HTTP-клиент `mcp/client.mjs`. Авторизация — только отдельные PERO_CRM_API_URL/PERO_CRM_API_KEY; старый секрет/облачный fallback отсутствуют. Публикация работает по сохранённой ревизии, стабильным ID и UUID операции. Восстановление результата после сетевой ошибки выполняет GET прежнего receipt; Python сохраняет UUID и fingerprint на диск до записи.
