# Поля, перенос и деньги

Одна строка `items` — целое изделие или согласованная сборка; `qty` — количество изделий, `price` — цена единицы. `products` — блоки характеристик этого изделия: «Каркас», «Фасад», «Столешница», наполнение. Они не создают отдельные изделия CRM.

| Поле | Использование |
|---|---|
| `id` | Неизменяемый ID позиции; сохранять при перестановке и правке |
| `name` | Название цельного изделия, при необходимости помещение |
| `description` | Сохранять имеющееся; не добавлять описание без задачи |
| `size` | Подтверждённые общие L × H × D в мм; не размер комнаты/матраса/одного модуля |
| `qty`, `price` | Количество и цена единицы в исходной валюте КП |
| `note` | Согласованные уточнения состава/стоимости |
| `image`, `image2` | Приватные токены `kp-media:<id>` этого КП |
| `dbl` | Полный лист с двумя настоящими видами/деталями либо поллиста |
| `products` | title, outer, inner, hinges, drawers, lighting |

В `title` указывать компонент, конструкцию и подтверждённое наполнение; в `outer`/`inner` — материалы, отделку, цвет/декор. Наполнение/фурнитуру не дублировать в нескольких блоках. Считать ящики, штанги и полки на изделие и весь qty; лоток не увеличивает количество ящиков. Фальш-фасад/шов не доказывает ящик. Не угадывать марку материала или скрытую конструкцию по визуальному сходству. Неполные размеры не дополнять выдуманными числами; согласованные текстовые размеры сохранять. Подсветку указывать внутри компонента; температуру брать из задания, согласованное пользовательское значение имеет приоритет.

«Оформи как КП X» переносит подачу, не спецификацию. «Материалы как X» разрешает только названные категории. Точный перенос всей позиции требует свежего GET исходника и всех её полей/изображений; удалить исходный item.id, получить новый серверный ID, изображения загрузить новому владельцу. Источник не менять. Клиента, доставку и общие условия переносить только в согласованном объёме.

Изменять реальные `price`, `discount`, `delivery`, а не примечание с обещанной новой суммой. Неизвестная цена — 0 с отметкой незавершённого расчёта, а не бесплатная мебель. Цена комплекта и цена единицы различаются. Существующие валюта, скидка, оплата и сроки сохраняются, пока их не просили менять.

Печатные суммы рассчитывает исходный шаблон, перенесённый в `@pero/kp-template`; не заменять его округление своей формулой. CRM пересчитывает зафиксированный курс в BYN через Decimal: initialPrice единицы до скидки, expectedPrice после скидки. Услуги участвуют в пропорциональной скидке; отдельная поправка проекта сохраняет общий итог до копейки. Исторические начисления не пересчитываются.

Для `delivery.mode=total` указать общую сумму, не выдумывать разделение. Для `mode=items` каждая строка хранит `crmKind=DELIVERY|UNLOADING|INSTALLATION`; произвольная подпись не определяет категорию. Сохранять исходные печатные подписи, price и согласованный итог строк. При выключенных услугах суммы не участвуют в итоге.
