# Proposal

## Why

Согласованная задача №106 добавляет длительность записи личного плана. Сейчас календарь хранит только дату, поэтому последующие итоги часов и аналитика не имеют надёжного источника.

## What Changes

- Необязательное поле «Количество часов» в создании и редактировании записи.
- Хранение целых плановых минут; пустое значение остаётся NULL, явный ноль сохраняется.
- Общие преобразование часов и форматирование длительности, прежние права, личная область и CAS/retry.
- Добавочная миграция без пересчёта истории. Итоги и аналитика выделены в №107/108.

## Capabilities

### New Capabilities
- `calendar-planned-duration`: необязательная плановая длительность личной записи.

### Modified Capabilities

Нет: в основной библиотеке OpenSpec календарных capabilities пока нет.

## Impact

CalendarEntry, server/calendar contracts/core, PersonalCalendar и проверки. Production не выпускается; local/staging без дампов, Restic не затрагивается.
