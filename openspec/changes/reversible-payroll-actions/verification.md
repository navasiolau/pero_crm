# Проверка

- Prisma Client сгенерирован, TypeScript `tsc --noEmit --incremental false`, ESLint затронутых интерфейсов и ядер, OpenSpec strict и `git diff --check` прошли.
- 94 целевых теста прошли. Проверены кассовый отчёт, роль, формы касс, расчёт долга, частичный пакет и повтор его квитанции, исходные сдельные начисления и формула процента после компенсации.
- В существующую защищённую PostgreSQL-фикстуру CI добавлены сценарии восстановления аванса и нехватки кассы, отмены и восстановления точного состава частичного пакета, запрета изменения компенсации и защиты проведённой выплаты. Рабочая БД в локальных проверках не использовалась.
- Исторические записи Журнала без обратимой команды остаются доступными для чтения. Если удалить старую действующую выплату после обновления, новое действие создаст команду восстановления с сохранённым снимком.
- Регрессия #244 после объединения проверена отдельно. Закупщик и закупщик с ролью менеджера при отмене зарплаты читают только вид выплаты и получают отказ. Бухгалтер и другие разрешённые роли получают подтверждение после мягкой отмены и записи команды восстановления. Пустая задолженность возвращает штатное сообщение после проверки квитанции пакета. 28 целевых проверок прошли.
- CI и фактическая staging-приёмка ожидаются при общей интеграции.
