# Design

Используем финансовые ссылки проектов и действующие серверные ядра платежей и закупки. Храним только отправляемые команды и идентификатор актёра до получения результата. Повтор с исходным UUID привязан к актуальному пользователю личного чата. При смене привязки сохранённая команда недоступна новому пользователю.
