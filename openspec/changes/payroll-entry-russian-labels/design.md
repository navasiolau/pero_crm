# Design

## Context

`PayrollEntry.scheme` хранится строкой. В исходном расчётнике нет подписей прямых процентов инженера и монтажника, поэтому показываются технические коды. Новые начисления инженера уже используют только `PRODUCT_PERCENT_ENGINEERING`; `PRODUCT_ENGINEERING` сохраняется в исторических финансовых записях. Владелец 07.10.2026 исключил устаревший и любые резервные типы из отображения. `DataTable` использует `sortValue` также для поиска.

## Goals / Non-Goals

**Goals:** единая подпись в ячейке, сортировке и поиске; русские названия действующих типов без резервных категорий и старой инженерной схемы.

**Non-Goals:** изменение схем оплаты сотрудника, алгоритмов начисления, SQL, прав доступа и сумм.

## Decisions

- Дополнить существующий словарь и добавить небольшую общую функцию получения подписи. Это сохраняет одну точку перевода; повторяющиеся резервные выражения в таблице могли бы разойтись.
- Удалить `PRODUCT_ENGINEERING` из словаря; для него и других отсутствующих собственных ключей возвращать пустую строку. Не фильтровать строки начислений и не присваивать исторической записи новый тип. Проверка собственного ключа защищает также от совпадения кода с именем свойства прототипа.
- В расчётнике изменить только заголовок и получение подписей. В финансовой сводке колонка относится к схеме оплаты сотрудника и использует другой, уже полный словарь.
- Обновить существующую проверку подписи сборщика. Проверку реальных компонентов и CSS провести временным браузерным сценарием с шестью действующими типами; сохранность старой/неизвестных строк проверить отдельно. Обзор для владельца содержит только действующие названия. Новые записи БД не нужны.

## Risks / Trade-offs

Длинные русские подписи занимают больше места → проверить реальную таблицу, поиск и сортировку при 1440×900, 390×844 и 360×800.

## Migration Plan

Миграций и дампов БД нет. После локальных проверок — отдельный разрешённый владельцем коммит, обычный merge в staging и приёмка фактически развёрнутой ревизии; выпуск в main по отдельному указанию владельца.
