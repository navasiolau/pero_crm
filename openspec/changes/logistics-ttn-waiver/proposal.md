# Proposal

## Why

Некоторые рейсы оформляются без ТТН. Сейчас рейс сохраняется, но провести его расход без файла нельзя. Владелец согласовал явное исключение для выбранного рейса.

## What Changes

- Добавить сохраняемую галочку «ТТН не требуется» в создание и редактирование рейса.
- Разрешить проведение и исправление без ТТН только при включённой галочке, сохраняя её снимок в проведении.
- Сохранить остальные денежные проверки, доступ и проверку каждого переданного документа.

## Capabilities

### New Capabilities

- `logistics-ttn-waiver`: явное исключение требования ТТН с серверной и PostgreSQL-проверкой.

### Modified Capabilities

Нет опубликованной основной спецификации логистики; исходные требования находятся в changes №123–125. Этот change добавляет согласованное исключение к ним.

## Impact

Форма и реестр логистики, серверные контракты и проведение, внутренний writer Payment, схема и аддитивная миграция. Зависимости и обычные финансовые расходы не изменяются. Задача №197, ветка feature/197; план и реализация согласованы владельцем 29.10.2026. Коммиты и production-выпуск согласуются по AGENTS.md.
