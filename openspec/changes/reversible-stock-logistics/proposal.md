# Why

Ввод и мягкое удаление обычных складских операций должны быть обратимы из журнала при сохранении финансовых и складских фактов.

# What Changes

- Добавить проверенный откат обычного прихода, оплаченной закупки, выдачи и возврата через действующий план удаления.
- Добавить восстановление группы из сохранённых снимков баланса, факта выдачи, возвратов и платежей.
- Упростить повторный откат через журнал без потери истории предыдущего удаления.
