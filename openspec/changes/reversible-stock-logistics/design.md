## Decisions

- Веб, Telegram и API используют общий складской writer. Для стандартного оплаченного прихода один корень связывает склад и платёж.
- Откат создания разрешает только проверенный ожидаемый набор движений. Поздние зависимые действия блокируют откат.
- Удаление хранит обратимый снимок. Восстановление проверяет ревизию склада, актуальность затронутых потребностей и достаточность кассы/баланса. Фактические суммы, документы, связи и идентификаторы сохраняются.
- Операции оплаченного чека сохраняют собственные обработчики. Обычная логистика относится к отдельной задаче №260.
