# Proposal: обязательные ставки, правка до DONE, живой перерасчёт

## Контекст

Решения владельца 06.10.2026: (1) поле процента не бывает пустым — пустое = `0` (не `NULL`); (2) менеджер/директор/админ меняют % вплоть до статуса DONE, дальше закрыто; (3) при перетаскивании идёт расчёт планируемой ЗП, после начисления менеджер всё ещё может менять % (специалист видит изменение суммы); (4) превью суммы пересчитывается мгновенно при вводе, без перезагрузки.

## Цель

- Backfill: существующие `NULL`-ставки конфигов и настроек → `0` миграцией; новая запись `NULL` запрещена везде (схемы, формы, создание изделий).
- Правка `ratePercent`/`assigneeId` менеджерскими ролями разрешена при любом статусе кроме DONE; при DONE сервер отклоняет с понятной ошибкой.
- Изменение ставки после SETTLED (не DONE) пересчитывает снимок и создаёт корректирующую запись зарплаты дельтой в текущем месяце (аудит ChangeLog, уведомление специалисту); пропущенное начисление (SKIPPED_ONCE) с заданной позже ставкой добирается при следующей смене статуса.
- Превью в карточке и настройках считается от вводимого черновика.

## Non-goals

- Смена исполнителя после начисления не переносит деньги (как раньше).
- Закрытие месяца/выплаты не вводятся; корректировки — дельтами в текущем месяце.
