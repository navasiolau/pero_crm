# Proposal

## Why

Стрелки ставки сейчас используют 0.1%; владелец согласовал шаг 0.5% в изделии.

## What Changes

- Точный шаг 0.5 процентного пункта кнопками и клавиатурой для трёх специалистов, границы 0–100, прежний ручной ввод/NULL/ноль/CAS/UUID. Стандартные проценты не меняются.
- Задача 76, ветка bugfix/76; область согласована владельцем 05.10.2026 в запросе реализации плана75–78.

## Capabilities

### New Capabilities

- `product-percentage-half-step`: Точный шаг 0.5 процентного пункта кнопками и клавиатурой для трёх специалистов, границы 0–100, прежний ручной ввод/NULL/ноль/CAS/UUID. Стандартные проценты не меняются.

### Modified Capabilities

Нет изменений основных спецификаций; связанные действующие changes сохраняют свою историю.

## Impact

Общий PercentageRateInput и его арифметика/тесты; API/схема БД остаются прежними.
