# Proposal

## Why

Задача 135 устраняет подтверждённое голодание outbox: первые 50 постоянно падающих событий мешают получить следующее исправное. Параллельные вызовы сейчас не получают исключительное владение событием, а штатный фоновый запуск в существующем web runtime отсутствует.

## What Changes

- Событие получает атомарную ограниченную аренду; подтверждение и повтор допустимы только текущему владельцу. После потери worker событие возвращается в очередь по истечении аренды.
- Отказы планируют следующую попытку с ограниченным backoff. Исчерпанные попытки остаются видимыми, ID/payload/история сохраняются; завершённые события не переоткрываются.
- Существующий Node web runtime запускает один явно включаемый worker, без отдельного сервиса и без автоматического запуска на import/build. Оператор получает безопасные агрегаты очереди и возраст ожидающих событий.
- Внутренняя очистка старого эскиза использует то же владение/подтверждение и сохраняет точные существующие проверки ключей, ссылок и обычный retry подтверждённой загрузки.
- Добавляются additive migration, injected-clock/отказные тесты и native PostgreSQL concurrency/expiry/migration проверки на существующем разрешённом local/staging.

## Capabilities

### New Capabilities

- `reliable-domain-event-queue`: продвижение outbox после ошибок, ограниченное владение, возврат после сбоя, наблюдаемое исчерпание и штатный фоновой запуск.

### Modified Capabilities

Нет. Независимая доставка каждому subscriber и идемпотентность внешних эффектов относятся к задаче 136; устранение context↔events цикла — к 152.

## Impact

Модель DomainEvent и новая additive migration; queue modules, events dispatcher и Node instrumentation; внутренний sketch cleanup adapter; существующий API dispatch с защищённой диагностикой; `.env.example`, операторская документация и тесты. UI, денежные данные, plugin recipients contract, SDK version, storage keys и точная семантика удаления не меняются. Commit/merge/push/staging координирует root после независимого review; main/production запрещены.
