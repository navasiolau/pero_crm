# Проверка

TypeScript, OpenSpec strict и 1691 веб-тест прошли. Мобильный Chromium проверяет нижнюю панель при прокрутке на ширинах 360, 390 и 430 px, все финансовые разделы и ограничение доступа к зарплате, поиск и карточки касс, форму добавления кассы, фильтры расходов, вложенный просмотр и ссылку скачивания ТТН. Проверка открывает светлую и тёмную темы с тестовыми данными.

Веб-CRM продолжает использовать таблицы и обычные формы. В Telegram рабочее пространство переиспользует эти же страницы и серверные действия. Тесты области доступа проверяют отказ для уведомлений в ограниченной сессии.

При staging-приёмке сравнить SHA образов с прошедшим CI, проверить HTTPS-вход, развёрнутый CSS мобильной оболочки, отказ вне рабочей области и доступность выдачи сессии для исходного Telegram origin.
