# Design

## Context

Views подтверждают текущий запрос и закрытие мобильной панели; ProductsKanban дополнительно подтверждает источник строк и роли. Общий hook преждевременно выставляет done до измерения карточки. См. proposal.md и действующие changes №117/145.

## Goals / Non-Goals

**Goals:** сохранить ожидающий поиск при временно отсутствующей или скрытой карточке и выполнить одну прокрутку по обеим осям после её измерения.

**Non-Goals:** менять семантику фильтрации, серверные права, оптимистичный DnD, геометрию канбана или структуру предпочтений.

## Decisions

1. Установка done переносится после проверки ненулевых размеров доски и карточки. Отсутствующий точный ID в подтверждённых данных по-прежнему завершает запрос без прокрутки.
2. Ожидающий hook наблюдает изменения дочернего DOM доски и размеры доски/целевой карточки. События объединяются в один RAF. После успеха, отмены запроса, потери готовности или unmount observers отключаются. Постоянного цикла RAF нет.
3. Общие расчёты координат и восстановление mobile snap остаются прежними. Новые массивы/SSE после успеха не повторяют переход.
4. В существующем browser harness воспроизвести скрытую и поздно вставленную целевую карточку. Проверить desktop/mobile, один переход, caret и прежнюю геометрию; не создавать отдельный дублирующий набор тестов.

## Risks / Trade-offs

- Устаревший callback → cleanup RAF/observers и проверка текущего query.
- Неограниченный polling → только события DOM/resize, прекращение после успеха.
- Изменение прав №194 → финальный общий прогон выполняется с принятыми фильтрами и ролями; скрытая сервером карточка не становится целью.

## Migration Plan

Без миграции. Local targeted browser + lint/типизация; обычный merge и один общий CI/реальный staging с SHA и образом. Production отдельно.
