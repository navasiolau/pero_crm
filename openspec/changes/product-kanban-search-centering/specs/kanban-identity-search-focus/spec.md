# Spec Delta

## Purpose

Обеспечить устойчивое центрирование карточки по точному отображаемому номеру после применения поисковых результатов, ролевых ограничений и появления измеримого интерфейса.

## ADDED Requirements

### Requirement: Дождаться измеримой карточки точного результата

Канбан MUST сохранять ожидающее центрирование точного совпадения, пока его карточка временно отсутствует в DOM либо не имеет размера. После готовности он SHALL один раз приблизить её к центру по горизонтали и вертикали в доступных пределах, сохранив размеры колонок, фильтры, вид и фокус ввода.

#### Scenario: Карточка временно скрыта
- **WHEN** подтверждённый поиск содержит точный результат, но его карточка ещё имеет нулевой размер
- **THEN** поиск остаётся ожидающим и выполняет одно центрирование после появления ненулевого размера

#### Scenario: DOM-карточка появляется позднее
- **WHEN** точный результат подтверждён до вставки его DOM-карточки
- **THEN** вставка карточки завершает ожидающее центрирование без повторного ввода номера

#### Scenario: Частичный запрос или скрытый результат
- **WHEN** подтверждённый набор не содержит точного доступного номера
- **THEN** фильтрация сохраняется без принудительной прокрутки, включая последующий SSE

#### Scenario: Новый запрос отменяет прежний
- **WHEN** ожидающая карточка появляется после смены или очистки поискового текста
- **THEN** прежнее центрирование не выполняется
