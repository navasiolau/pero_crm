# Design

## Context

См. proposal.md. ProductKanbanCard и ProjectKanbanCard используют общий ProductHeroImage с object-contain и h-auto. Вложенная доска изделий и drag overlay уже переиспользуют эти карточки. Требование естественной высоты из change задачи 92 заменено решением владельца; остальные сценарии остаются.

## Goals / Non-Goals

**Goals:** одинаковый устойчивый кадр 3:4 в двух общих карточках, покрывающих все канбан-контексты.

**Non-Goals:** изменения подробного ProductSketchView/ProductHeroImage, оригиналов/серверных preview, ACL, маршрутов, финансов и БД.

## Decisions

- В карточках область миниатюры задаёт aspect-ratio 3/4. Кнопка и картинка заполняют её на всю ширину/высоту.
- Передать object-cover и object-center только из карточек. cn/tailwind-merge заменяет стандартный object-contain; подробные страницы продолжают использовать стандартное поведение.
- Существующая заглушка ошибки получает ту же полную высоту. Без назначенного изображения область не создаётся. Это исключает изменение геометрии при delayed/cache/error.
- Обновить существующий browser geometry test на реальные React-компоненты и Tailwind CSS. Проверять измерения областей, computed fit/position, крайние исходные пропорции, переходы/полноэкранный просмотр и блокировку при drag. Скриншоты дополнительно проверяются глазами.
- Альтернативы: естественная высота создаёт неравномерные карточки; object-contain в фиксированном кадре даёт поля; глобальная смена Hero нарушила бы подробный просмотр. Поэтому используется локальное переопределение в канбане.

## Risks / Trade-offs

- Крайние пропорции теряют края в миниатюре → центрированный crop согласован владельцем, оригинал и подробный просмотр доступны целиком.
- Геометрия CSS и ошибочного preview может отличаться от ожидаемой → реальные browser checks на 1440px, 390px и 360px, delayed/error/cache и drag.

## Migration Plan

Миграций нет. Локальный review → обычный merge в staging основным агентом после разрешения на коммит → приёмка фактически развёрнутого SHA. Возврат UI выполняется обычным GitFlow; production и restic в этой задаче не затрагиваются.
