# Proposal

## Why

Текущий журнал показывает технические идентификаторы и коды, обрезает значения до 60 символов и не позволяет прочитать событие целиком. Администратору нужна понятная таблица и полная карточка события с наглядным сравнением.

## What Changes

- Оставить колонки «Время», «Пользователь», «Сущность», «Действие», «Было → стало»; убрать источник и повторяющуюся подпись типа автора из таблицы.
- По клику строки открывать единую большую карточку события, по кнопке «Показать изменения» открывать ту же карточку на сравнении.
- Показывать полные значения с красным `−` и зелёным `+`, причину, инициатора, источник, связанные сущности и безопасные технические сведения.
- Подключить серверные фильтры, поиск, сортировку и пагинацию №222 через общий компонент, готовый для контекстов №224.
- Обеспечить клавиатурное открытие строки, возврат фокуса, обработку ошибок и устаревших ответов без раскрытия чужого события.

## Capabilities

### New Capabilities

- `journal-readable-interface`: понятное представление списка и полной карточки события, доступное исключительно ADMIN.

### Modified Capabilities

Нет.

## Impact

Задача №223, ветка `feature/223`, исходный staging `a391e5f1df7f307905513df7e1d46a10bee09a01`. Изменяются общий экран журнала, новые компоненты `components/journal`, опциональная клавиатурная активация строк DataTable и целевые браузерные тесты. Используются контракт №221 и серверное чтение №222; миграции, доменные writers и страницы проектов/изделий принадлежат отдельным задачам. Новых библиотек и публичного REST API нет.
