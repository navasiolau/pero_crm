# Proposal

## Why

При выходе из проектов или изделий CRM забывает фильтры, поиск, сортировку и страницу: в `UserPreference` сохраняется только вид списка. Пользователю приходится повторять выбор после каждого перехода, а отложенный поиск может восстановить уже сброшенное значение.

## What Changes

- Сохранять полный набор параметров проектов и изделий отдельно для текущего пользователя и раздела.
- Восстанавливать состояние на голом маршруте, оставляя явному URL полный приоритет.
- Сбрасывать сохранённое состояние по «Сбросить», отменять устаревший поиск и защищать запись от гонок.
- Сохранить действующие серверные ограничения доступа; фильтры не предоставляют дополнительных прав.

## Capabilities

### New Capabilities

- `persistent-list-state`: сохранение, восстановление, приоритет URL, сброс и изоляция состояния списков.

### Modified Capabilities

Нет существующих спецификаций, требующих изменения.

## Impact

Страницы и клиентские компоненты `/projects` и `/products`, общий `useListParams`, чтение/запись `UserPreference`. Используется существующая таблица, без миграции бизнес-данных. Публичные API и ролевые права не изменяются. Проверки — node:test/tsx, локальный браузер, затем staging силами оркестратора.
