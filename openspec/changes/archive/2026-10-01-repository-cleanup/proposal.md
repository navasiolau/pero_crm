# Proposal

## Why

AGENTS.md занимает около 60 КБ и смешивает обязательные правила с историей реализации, старыми паролями и противоречивыми описаниями модели. Первоначальные планы и локальные артефакты прежних проверок затрудняют работу с актуальным проектом.

## What Changes

- Задача №2, ветка `bugfix/2` от свежего `origin/staging`; единая последовательная нумерация новых веток всех разрешённых типов.
- Сократить AGENTS.md до 8 КБ, сохранив требования владельца, краткий контекст, команды и обязательные ссылки безопасности.
- Удалить четыре первоначальных плана, старый протокол встречи и шаблонный README приложения; актуализировать корневой README и ссылки действующих документов.
- Удалить по проверенному списку старые локальные браузерные артефакты, три dev-лога и tsbuildinfo в основной копии. Действующую приёмку сохранить; недоступный pytest cache пропустить без изменения ACL.
- Снять три тестовые B3D-модели с Git-учёта и исключить каталог из Git/Docker, сохранив локальные файлы.

## Capabilities

### New Capabilities

Нет: документация и локальная гигиена репозитория; `skip_specs: true`.

### Modified Capabilities

Нет: API, модель БД и поведение приложения сохраняются.

## Impact

Изменяются только документация, ignore-файлы, Git-учёт тестовых моделей и собственные OpenSpec-артефакты. Основная рабочая копия и её незакоммиченные изменения сохраняются; удаление локального мусора имеет отдельный ограниченный список. Действующие планы, specs, приёмка, секреты, загрузки и инфраструктура защищены от изменений.

Объём согласован владельцем прямым поручением «PLEASE IMPLEMENT THIS PLAN» для задачи №2 от 01.10.2026. Этот change фиксирует тот же план без расширения; отдельного разрешения на коммиты и выпуск поручение не содержит.
