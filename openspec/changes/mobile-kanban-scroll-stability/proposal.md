# Proposal

## Why

При горизонтальном свайпе мобильного канбана пользователь видит сильное дрожание доски и не может перейти к следующим колонкам. Общий контейнер проектов и изделий синхронизирует две полосы прокрутки в обе стороны; асинхронное отражение позиции не должно вмешиваться в активный жест и нативную инерцию.

## What Changes

- Устранить обратную запись отражённой прокрутки в её текущий источник.
- Сохранить обычный мобильный свайп по карточкам, вертикальную прокрутку страницы и доступ к последующим колонкам.
- Сохранить нижнюю полосу, клавиатурную прокрутку, Shift+wheel, отдельную ручку DnD и восстановление позиции/поиск задачи №212.
- Проверить настоящие touch-жесты в браузере на двух глобальных досках и зафиксировать ограничения эмуляции телефона.

## Capabilities

### New Capabilities

- `mobile-kanban-scroll-stability`: стабильная горизонтальная прокрутка общего контейнера без обратной связи между двумя полосами.

### Modified Capabilities

Нет.

## Impact

Общий `KanbanScrollArea`, при необходимости узкая утилита синхронизации и browser regression. Серверные действия, БД, бизнес-правила, фильтры, API и зависимости не меняются. Доска задач использует отдельную реализацию и затрагивается только при подтверждении той же причины.
