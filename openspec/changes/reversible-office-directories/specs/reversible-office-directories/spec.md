## ADDED Requirements

### Requirement: Обратимые операции офисных справочников

Система SHALL записывать обратимую команду для штатных изменений офисных справочников с сохранением исходных идентификаторов.

#### Scenario: Независимое изменение соседнего поля

- **WHEN** после записи Журнала изменилось поле, которое команда не затрагивает
- **THEN** подтверждённая отмена сохраняет новое значение соседнего поля

#### Scenario: Повторное изменение того же поля

- **WHEN** между записью Журнала и отменой проведено новое изменение того же поля
- **THEN** подтверждение проверяет происхождение значения и отказывает при конфликте

#### Scenario: Созданная запись имеет зависимость

- **WHEN** созданный клиент, контрагент, касса, статья или расценка уже используются
- **THEN** сервер отказывает в отмене создания

#### Scenario: Связанный контакт или касса по умолчанию

- **WHEN** штатное изменение обновило контактное лицо проектов или сняло назначение кассы
- **THEN** подтверждённый откат восстанавливает проверенные значения атомарно
- **AND** при конфликте связанных данных сервер отказывает без частичного изменения
