# Проверка №264

Локальные тесты watcher проверили два последовательных выпуска в защищённом production-профиле, повторное обнаружение того же образа, ошибку миграции до замены web и renderer, несовпадающие адреса, образы и файлы секрета. После ошибки здоровья уже заменённой пары production требует операторского восстановления. Проверка показывает, что старый root-web не стартует с новым файлом секрета.

В Windows прошли 93 из 95 тестов операторских сценариев, два теста пропущены по платформе. Прошли проверка синтаксиса runtime и строгая проверка OpenSpec.
