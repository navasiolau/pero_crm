## ADDED Requirements

### Requirement: Защищённое рабочее соединение production
Штатный watcher SHALL поддерживать явно включённый защищённый режим для production-проекта `crm` в `/opt/crm` с основным образом `:main`. Каждый следующий выпуск SHALL выполнить миграции и сверку грантов под мигратором до переключения сервисов. Рабочий web SHALL запускаться с отдельной ограниченной ролью и без доступа к учётным данным мигратора.

#### Scenario: Два последовательных выпуска
- **WHEN** CI публикует два последовательных выпуска в защищённую production-среду
- **THEN** каждый раз используется утверждённый образ этого выпуска, мигратор применяет схему, а рабочий LOGIN проходит проверку прав. Идентификатор и том действующего PostgreSQL сохраняются.

#### Scenario: Ошибка до замены пары
- **WHEN** не совпадают среда, образ или путь секрета либо штатная миграция завершается ошибкой
- **THEN** действующие web и renderer не заменяются. Старый root-web не получает доступ к новому файлу секрета при любом откате.
