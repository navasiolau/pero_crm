## Context

Web и renderer публикуются штатным main CI. Отдельный runtime LOGIN должен применяться и при следующем плановом обновлении. Пароль владельца хранится в файле root с режимом 0400.

## Decisions

- Использовать действующий этап миграции неизменяемым образом и обновления грантов. Оба окружения проверяют свой hostname, каталог, проект, тег, подключение к DB и привязку секрета.
- Запускать готовый web от UID/GID 1000. Восстановление старого root-web требует исходной конфигурации и изоляции от нового секрета.
- Перед первым production-переключением подготовить один полный дамп с изолированным восстановлением, репетицией миграций и сохранёнными исходными образами. Для возврата к точке дампа учитывать записи, поступившие позднее.
