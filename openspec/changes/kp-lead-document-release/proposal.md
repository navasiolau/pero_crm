# Proposal

## Why

При возврате перенесённого КП в «Лид» сохранение первого курса может завершиться конфликтом первичного ключа журнала. Изделие с прежним номером должно сохранять свою карточку и историю при выпуске КП и договора.

## What Changes

- В общей транзакции сохранения восстановить однозначную связь прежней позиции с активным изделием проекта до синхронизации состава.
- Связывать записи о скрытии изделий с событием КП. Выпуск из редактора подготавливает недостающий курс на дату КП и использует подтверждённую редакцию.
- Проверить выдачу PDF, договор первым действием и повтор после потери ответа в реальном редакторе staging.

## Capabilities

### New Capabilities

- `kp-lead-document-release` — выпуск документов из редактируемого перенесённого КП.

## Impact

Сервер сохранения КП, транспорт редактора и тесты. Используются существующие API и таблицы.
