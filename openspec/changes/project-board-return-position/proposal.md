## Why

Канбан изделий внутри проекта теряет положение при возврате из карточки. Исправление №212 охватывало две глобальные доски.

## What Changes

- Восстанавливать положение доски и страницы, включая нижнюю полосу, по кнопке браузера и стрелке в карточке.
- При открытии изделия записывать вкладку «Изделия» в исходную запись истории.
- Хранить снимок отдельно для пользователя и проекта в текущей вкладке браузера.

## Capabilities

### Modified Capabilities

- `persistent-list-state`: применить восстановление позиции к вкладке «Изделия» проекта.

## Impact

Клиентский код доски и браузерные проверки. Миграции не требуются.
