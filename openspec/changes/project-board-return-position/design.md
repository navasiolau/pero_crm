## Context

№212 восстанавливает позицию глобальных досок. Канбан проекта использует тот же горизонтальный контейнер и закреплённую полосу. Вертикаль принадлежит странице.

## Decisions

- Переиспользуем снимок с координатами, размером окна и ID карточки. Ключ вложенной доски включает путь проекта и ID пользователя.
- Сохраняем снимок в обработчике открытия карточки. Тело и обложка используют один обработчик. Ручка перетаскивания его не вызывает.
- Перед переходом добавляем `tab=products` в текущую запись истории, сохраняя остальные параметры. При возврате текущий URL имеет приоритет над вкладкой из серверного кэша Next. Существующая проверенная ссылка возврата остаётся каноническим адресом вкладки.
- Возвращаем якорь после появления доски и отражаем положение в нижней полосе. При исчезновении карточки ограничиваем сохранённые смещения текущими размерами.
