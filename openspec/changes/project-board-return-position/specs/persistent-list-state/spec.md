## ADDED Requirements

### Requirement: Возврат к изделиям конкретного проекта

Вкладка «Изделия» проекта SHALL восстанавливать горизонтальное положение канбана и вертикальное положение страницы после открытия изделия.

#### Scenario: Возврат из карточки

- **WHEN** пользователь открывает изделие нажатием на карточку или обложку и возвращается кнопкой браузера или ссылкой в карточке
- **THEN** открывается вкладка «Изделия» того же проекта, карточка возвращается на прежнее место в пределах доступной области, нижняя полоса соответствует доске

#### Scenario: Карточка исчезла

- **WHEN** карточки больше нет среди доступных изделий
- **THEN** доска и страница используют прежние смещения в пределах действующей области прокрутки

#### Scenario: Независимые позиции

- **WHEN** пользователь открывает другой проект, глобальную доску или входит под другой учётной записью
- **THEN** позиция предыдущего проекта не применяется к этой доске
