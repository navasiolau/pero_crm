# Verification

Пройдены проверки типов, OpenSpec и целевые тесты файлов, обложек, эскизов, очереди и транзакционного восстановления. Тесты загрузки проверяют отсутствие вызовов физического удаления после замены и при обработке старых событий очереди. Сценарии PostgreSQL и S3 обновлены для проверки сохранности байтов, версий и ответа 404 после удаления по прямому URL.

Перед применением миграции следует остановить обработчики и writers старой версии CRM. SQL отменяет ожидающие задания физической очистки. Начатый сетевой запрос старого процесса может завершиться за пределами транзакции. Отправка новых заданий удалена, миграция к действующей БД в этой работе не применялась. Возможность восстановления старых физически удалённых записей и байтов остаётся неизвестной.

Регистрация доменной отмены в общем журнале зависит от интеграции контракта задачи №240.
