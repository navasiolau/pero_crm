## Context

Списки уже открываются в портале. Во время открытия библиотека добавляет рядом с кнопкой фиксированные элементы для управления фокусом. Правило `space-y-1` учитывает их в порядке дочерних элементов и добавляет кнопке отступ снизу.

## Decisions

Использовать вертикальную flex-разметку с `gap-1` для подписи и поля. При расчёте промежутков браузер учитывает только элементы в потоке. Существующий компонент списка отвечает за позиционирование, поиск и фокус.

Высоту списка ограничить доступным местом, которое рассчитывает позиционер, как в остальных выпадающих меню CRM. В области вариантов ограничить передачу вертикальной прокрутки странице через `overscroll-behavior-y`. Воспроизведение на staging показало, что у последнего варианта следующее движение колеса прокручивало страницу на 210 пикселей.

Для двух фильтров Журнала использовать ширину кнопки из CSS-переменной Base UI `--anchor-width` и выравнивание по началу поля. Позиционер обновляет размер при изменении ширины формы. Список сохраняет горизонтальный масштаб во время появления и закрытия.

## Verification

В браузере измерить положение формы, кнопки и первой записи, а также прокрутку страницы. Повторить открытие, поиск, выбор и закрытие на компьютере и телефоне.

Сравнить левую и правую границы раскрытого списка с кнопкой на широком экране, на экране с переносом полей и на телефоне. Изменить ширину формы, пока список открыт.
