## ADDED Requirements

### Requirement: Стабильное положение Журнала при работе с фильтрами

Журнал SHALL сохранять положение формы, записей и прокрутки при открытии, поиске и закрытии списков «Пользователь» и «Сущность». Требование распространяется на общий Журнал, историю проекта и изделия, на компьютере и телефоне.

#### Scenario: Открытие списка на прокрученной странице

- **WHEN** пользователь открывает один из списков и вводит текст для поиска
- **THEN** варианты видны поверх страницы, а форма, записи и положение прокрутки остаются на месте

#### Scenario: Прокрутка вариантов до конца

- **WHEN** пользователь прокручивает длинный список вариантов до границы и продолжает прокрутку внутри списка
- **THEN** положение страницы сохраняется

#### Scenario: Возврат из списка к фильтрам

- **WHEN** пользователь выбирает вариант, нажимает Escape либо закрывает список нажатием за его пределами
- **THEN** список закрывается без сдвига страницы, а выбранный фильтр применяется по кнопке «Применить»
