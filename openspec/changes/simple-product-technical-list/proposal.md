# Proposal

## Why

Владелец 12.11.2026 отклонил конструктор разделов №214–215. Нужен простой нумерованный список в существующем поле изделия: постоянные заголовки, прямой ввод с автосохранением, единый JSON и только относящиеся к списку данные из КП.

## What Changes

- Убрать из изделия и формы создания кнопки/конструктор/выбор групп/пояснения/исходное описание и отдельные поля description/size/note.
- Показать непосредственно строки существующего каталога, включая согласованные ранее столешницу, обивку и мягкое наполнение; значения вводятся без предварительных действий, сохраняются после ввода.
- Переносить из КП только характеристики с соответствующими названиями. Описания, размеры, примечания, цены и неизвестные блоки не входят в JSON списка изделия.
- Существующая JSONB-колонка, права, аудит, конфликтные проверки и авторитетная синхронизация сохраняются. Массовой обработки данных нет.

## Capabilities

### New Capabilities
- `simple-product-technical-list`: простой ввод и ограниченный перенос характеристик в поле изделия.

### Modified Capabilities
Основные specs этой области ещё не созданы; новые требования заменяют отклонённый UI historical changes product-technical-specifications и соответствующую Product-проекцию kp-structured-specifications.

## Impact

Product UI/create/controller/patch, product-only projection КП и tests. КП-редактор, PDF и исходные/выпущенные снимки не перестраиваются. Нет DB migrations. Ветка bugfix/216 от свежего staging. Прежнее разрешение на commit/push и проверку staging действует; production вне задачи.
