# Proposal

## Why

Телефон клиента не объясняет, с кем связываться по конкретному заказу: отвечать может назначенный представитель. Проекту требуется собственное редактируемое контактное лицо с удобной подстановкой ФИО клиента.

## What Changes

- Поле «Контактное лицо» рядом с «Телефон клиента», с обычным текстовым вводом и автосохранением.
- Галочка «Контактное лицо» в форме клиента; создание и изменение доступны ADMIN/DIRECTOR/MANAGER.
- Подстановка ФИО при создании проекта; включение галочки заполняет только пустые поля существующих неудалённых проектов.
- Сохранённый текст не следует за ФИО и снятием галочки. Подтверждённая смена клиента заменяет даже ручной текст по настройке нового клиента.

## Capabilities

### New Capabilities

- `project-contact-person`: контактное лицо проекта, разовое автозаполнение и согласованная смена клиента.

### Modified Capabilities

Нет.
