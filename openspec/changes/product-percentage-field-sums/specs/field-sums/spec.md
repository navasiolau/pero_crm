# Spec Delta

## Purpose

Устранить показ чужих назначенных сумм полевым ролям в карточке изделия.

## ADDED Requirements

### Requirement: Поле не получает чужие суммы с сервера

Система SHALL для ролей вне MANAGER/PROCUREMENT отдавать в секции `total`:
- сумму своей строки (`ownMember.amount`), если пользователь назначен на этап;
- прогноз `draftTotal`, если этап в DRAFT без назначенного и заданы ставка и цена;
- иначе null.

Чужие назначенные суммы SHALL NOT покидать сервер для поля.

#### Scenario: Сборщик не видит сумму монтажника

- **WHEN** сборщик открывает изделие, где монтажник назначен со своей суммой 98 BYN
- **THEN** секция INSTALLATION для сборщика содержит `total` null, карточка показывает «Сумма: —», имя монтажника видно

#### Scenario: Своя сумма и прогноз сохранены

- **WHEN** поле открывает свой назначенный этап и неназначенный DRAFT со ставкой
- **THEN** своя секция содержит свою сумму, неназначенная — прогноз, `%`/цена/база по-прежнему null

### Requirement: Клиент не подменяет отсутствие суммы полным итогом

`SinglePercentageRow` SHALL для `!canViewAll` использовать только `ownAmount` и прогноз неназначенного (`section.assignee == null ? section.total : null`), SHALL NOT fallback на полный `section.total` при чужом назначенном.
