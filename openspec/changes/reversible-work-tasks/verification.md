# Проверка №250

- Prisma Client, TypeScript, ESLint изменённых модулей и OpenSpec strict проверены.
- Целевая проверка переходов задач и работ, атомарности аудита, журналирования графа и эффектов прошла.
- Добавлен нативный сценарий с откатом. Проверяются Undo/Redo создания работы, откат плана работы и редактирования задачи с сохранением независимого срока, мягкое удаление, восстановление двух сторон графа, сохранение вложения, ACL и отказ для зависимой задачи с выработкой.
- Выполнение нативного сценария и визуальный контроль в окружении требуют интеграции миграции владельцем.

Покрытие дополнено откатом первоначального распределения, переноса доли из связанной записи, самоназначения и снятия зависимости. Сценарии проверяют повтор запроса, сохранение суммы, прежние ID и пары ключей, отказ для начисления и выполняемой зависимой задачи. Guarded PostgreSQL сценарии для групп и версий ребра подготовлены, выполнение остаётся частью CI.
