# Why

Удаление пользовательской работы или задачи должно сохранять исходную запись, связи и возможность восстановления из журнала.

# What Changes

- Ввести мягкое удаление пользовательских работ и задач.
- Сохранять предпосылки, последующие задачи и вложения для восстановления.
- Учитывать только действующие задачи и работы в рабочих списках, доступе, назначениях и операциях.
- Проверять версию состояния и исторические ограничения при восстановлении.
- Поддержать откат создания и редактирования обычных работ и задач через журнал с учётом независимых правок.
