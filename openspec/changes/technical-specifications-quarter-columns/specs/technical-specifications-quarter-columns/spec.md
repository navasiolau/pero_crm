# Spec Delta

## Purpose

Отдать большую часть ширины поля технического описания значениям материалов, оставив названиям ровно четверть доступного пространства колонок.

## ADDED Requirements

### Requirement: Соотношение 25 на 75
Поле SHALL использовать 25% ширины колонок для названия и 75% для значения на компьютере и телефоне. Вертикальная линия SHALL совпадать с границей колонок в редактировании, просмотре и ручном создании. Длинные названия SHALL переноситься без обрезки текста. Существующие данные и работа поля MUST сохраняться.

#### Scenario: Изменение ширины экрана
- **WHEN** поле открывается на 390 либо 1440 px
- **THEN** доли колонок составляют 25/75, линия совпадает с границей, содержимое не теряется и не выходит за рамку
