# Design

## Context

Одна CSS-переменная технического поля задаёт grid и линию: сейчас 48% mobile/42% desktop.

## Goals / Non-Goals

**Goals:** Установить 25% на всех ширинах.

**Non-Goals:** Изменение данных, API, автосохранения, legacy, генератора КП, БД и CI.

## Decisions

Заменить значение общей переменной на 25% и убрать md override. Остальные стили и обработчики сохраняются. Существующая browser-проверка ожидает 25%; прежняя проверка помещения каждого слова целиком заменяется проверкой отсутствия обрезки и сохранности полного текста, поскольку узкая колонка допускает переносы.

## Risks / Trade-offs

Длинные названия займут больше строк → штатный перенос и autogrow сохраняют полный текст. Проверка desktop/mobile и фактического staging выполняется без бизнес-правок.
