# Proposal

## Why

Администратор должен читать историю открытого проекта или изделия непосредственно в карточке. Общий журнал уже получает понятный интерфейс в №223; здесь тот же интерфейс подключается к точному контексту без выдачи журнала другим ролям и без загрузки до открытия.

## What Changes

- Добавить последнюю вкладку «Журнал» проекта после вкладок плагинов, только для ADMIN.
- Добавить последнюю секцию «Журнал» в существующую длинную страницу изделия, только для ADMIN; новых вкладок изделия нет.
- Передавать постоянный ID открытой сущности и загружать журнал проекта при открытии вкладки, изделия — при появлении секции в области просмотра.
- Сохранить действующие формы, роли остальных разделов и возврат в исходный список. DIRECTOR не получает исключения.

## Capabilities

### New Capabilities

- `journal-entity-context`: размещение и отложенная загрузка журнала конкретной сущности исключительно для ADMIN.

### Modified Capabilities

Нет.

## Impact

Задача №224, ветка `feature/224`, исходный staging `26f1d12ab131e673930475f30203e35797a062ce`. Меняются страницы проекта/изделия, композиция нижних секций изделия, минимальный EntityJournal wrapper и целевые tests. Используются reader №222 и UI №223 после штатной интеграции. БД, миграции, writers и права остальных функций не изменяются.
