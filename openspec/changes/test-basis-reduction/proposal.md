# Proposal

## Why

Задача №168: сократить перекрывающиеся тесты, helpers и QA без потери уникальных контрактов. Владелец уточнил обязательную цель: не менее 50% строк в прежнем tracked-text scope. База `da5bf32c`: web tests — 64 722 строки, общий test/QA scope — 69 662 строки; итоговые пределы — соответственно 32 361 и 34 831 строка. Файлы и автоматические suites считаются отдельно. Первая фаза принята на staging `e986e290` и сохраняет собственные результаты; продолжение той же атомарной задачи должно достичь уточнённой цели.

## What Changes

- Удалить доказанные дубликаты проверок и выведенные из текущей эксплуатации QA-копии; для каждого удаления указать сохраняемую проверку в `reduction-map.md`.
- Удалять осиротевшие helpers только после проверки всех ссылок и ручных операторских entrypoints; исправить затронутые ссылки в существующей контрактной карте.
- Свести повторяемые setup, fixture lifecycle и проверки к существующим доменным helpers; завершённые одноразовые release/migration/recovery workflows вывести из runnable scope с точной привязкой к неизменённым историческим evidence.
- Показать чистое сокращение не менее 50% строк без minify, уплотнения строк и снятия уникальных условий; пройти один итоговый автоматический прогон, локальные проверки и приёмку реально развёрнутого нового staging.

## Capabilities

### New Capabilities

Нет. Только сокращение тестового инструментария; `skip_specs: true`.

### Modified Capabilities

Нет. Поведение приложения и уникальные требования сохраняются.

## Impact

Allowlist реализации — только согласованные файлы тестов, helpers, QA и их существующие ссылки; окончательный список записан в `reduction-map.md` до удаления. Новые артефакты — только этот change; прежний cash QA-plan получает лишь актуальную отметку retirement. Runtime `src`, Prisma, зависимости и lockfile неизменны. Деньги, ACL, CAS, idempotency, rollback, S3, native guards и Chromium остаются покрыты существующими проверками. БД, данные, инфраструктура, main и production в задачу не входят.
