# Проверка задачи №237

Локальная ветка `feature/237`, исходная ревизия `3d68efed`. Владелец подтвердил, что при совмещении ролей сотрудник сохраняет право второй роли.

## Профильные проверки

До исправления два регрессионных теста воспроизвели ошибку просмотра без назначения. В одном случае сервер скрывал прежнее техническое описание, в другом — структурированные характеристики. После исправления независимый повтор пяти затронутых наборов тестов Node прошёл полностью, 40 из 40, без пропусков.

Проверки охватывают видимость изделий по этапам, обе формы хранения характеристик, явно пустой список и ограничения доступа к ценам. Запросы на правку от работника или монтажника отклоняются. Сочетание MANAGER и MOUNTER сохраняет управленческое право редактирования без назначения.

Полный набор тестов веб-приложения прошёл на тех же исходниках, 1569 из 1569, без ошибок, отмен и пропусков. В полном прогоне присутствует и тест новой функциональности. Проверка TypeScript (`tsc --noEmit --incremental false`), ESLint для шести изменённых файлов приложения и `git diff --check` прошли. Независимое ревью завершилось без замечаний.

Сборка `pnpm build` завершилась успешно, подготовлены все 37 страниц.

## Локальная CRM

Chromium прошёл 15 проверок на ширинах 360, 390 и 1440 пикселей. Работник без назначения видел технические строки изделий на производстве и складе, монтажник без назначения — на монтаже. Проверены пустое поле и доступный менеджеру редактор. Вручную просмотрены четыре снимка блока характеристик.

В собранной CRM с обычным service worker проверены ещё четыре перехода под работником и монтажником. Для каждой роли клик с вкладки проекта после гидратации страницы открывал нужную карточку. Переход из общей мобильной таблицы проверен по нативной HTML-ссылке при отключённом JavaScript, чтобы у локальных профилей не создавались пользовательские настройки. Во всех четырёх случаях возврат вёл к месту входа. Ошибок страницы при этих переходах не было. [Результаты проверки переходов](../../../apps/web/test-results/worker-technical-specifications-237/compiled-navigation.json)

Две недоступные карточки вернули HTTP 404. Сервер отклонил все четыре запроса на изменение от реальных профилей до начала транзакции. Сверка 13 контрольных таблиц и `UserPreference` подтвердила сохранность исходных данных. В существующих карточках с заполненными характеристиками использовались прежние текстовые данные. Структурированный JSON, явно очищенный список и сочетания ролей покрыты автотестами. [Результаты проверки карточек](../../../apps/web/test-results/worker-technical-specifications-237/qa-summary.json)

После приёмки временный веб-процесс завершён, порт 3104 свободен, локальный контейнер `pero_crm_pg` возвращён в исходное состояние `exited`. Обе ссылки выше ведут к локальным результатам в `apps/web/test-results`, исключённым из Git.
