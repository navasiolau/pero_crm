# Spec Delta

## Purpose

Дать владельцу личного плана подробную статистику часов и выполненных записей за выбранные включительные даты, согласованную с календарными итогами.

## ADDED Requirements

### Requirement: Inclusive date range analytics
Аналитика SHALL показывать плановые часы, часы выполненных записей, количество выполненных записей, разбивку по дням и записи за выбранные даты Europe/Moscow.

#### Scenario: Both boundaries
- **WHEN** выбран диапазон7–8 октября
- **THEN** учитываются записи с00:00 7 октября до конца8 октября по Москве, соседние дни исключены

#### Scenario: Completion later
- **WHEN** запись из выбранного дня выполнена позднее
- **THEN** она учитывается как выполненная по своей дате в плане

#### Scenario: Common totals
- **WHEN** выбран полный месяц
- **THEN** часы и число выполненных совпадают с календарём, отменённые часы исключены и пропуски видны

#### Scenario: Empty or invalid
- **WHEN** записей нет либо диапазон некорректен
- **THEN** пустой диапазон показывает0 и отсутствие записей; некорректный диапазон показывает понятную ошибку без чужих данных

### Requirement: Personal scope
Аналитика SHALL использовать только владельца из проверенной сессии с действующим личным доступом.

#### Scenario: Administrator isolation
- **WHEN** администратор открывает аналитику или передаёт идентификатор другого владельца
- **THEN** чужие записи и итоги не раскрываются

#### Scenario: Revoked access
- **WHEN** план отключён или учётная запись неактивна
- **THEN** чтение аналитики отклоняется

### Requirement: Calendar navigation and detail
План SHALL открывать аналитику выбранного месяца; аналитика SHALL позволять менять даты, искать записи и открывать соответствующий день.

#### Scenario: Selected month
- **WHEN** пользователь переходит в другой месяц и нажимает «Аналитика»
- **THEN** открывается этот месяц с обеими датами в URL

#### Scenario: Day detail
- **WHEN** открыт день из дневной разбивки
- **THEN** календарь показывает личные записи соответствующего дня
