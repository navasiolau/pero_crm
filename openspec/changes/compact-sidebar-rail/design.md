# Design

## Context

См. proposal.md. `AppShell` использует `Sidebar variant="inset"`. Базовый `--sidebar-width-icon` уже равен 3rem; inset-ветка добавляет 16 px к gap и 18 px к контейнеру и оставляет наружный p-2. При сворачивании текст PERO CRM остаётся в 32 px кнопке с gap-2. `SidebarContent` скрывает обе оси overflow, делая низ меню недоступным в коротком окне.

## Goals / Non-Goals

**Goals:** одинаковая ширина gap и контейнера, сохранённые доступные имена ссылок, вертикальный доступ к последнему разделу.

**Non-Goals:** изменение набора ролей, серверных операций, expanded-раскладки, режима floating и мобильных размеров.

## Decisions

- В свёрнутом inset-варианте убрать только добавочные наружные отступы и использовать существующий icon-токен 3rem. Уменьшение токена при сохранении inset-полей оставило бы ненужную ширину и сжало полезную область.
- Сохранить внутренние p-2 и кнопки 32 px: 48 px достаточно для строки иконки и двух полей по 8 px. Верхнюю кнопку центрировать; подписи переводить в sr-only в collapsed-состоянии. Просто overflow-hidden оставляет частично видимые буквы.
- Скрывать только горизонтальную ось overflow у collapsed-контента. Вертикальную прокрутку оставить внутри панели. Мобильный Sheet не имеет desktop group-data collapsed и остаётся полноразмерным.
- Проверить actual-компоненты с существующим Tailwind CSS в браузере без БД, затем передать root сценарии фактического staging.

## Risks / Trade-offs

- [Специфичность Tailwind для inset-padding и descendant-селекторов] → Проверять computed width/padding и фактическую геометрию, не только строки классов.
- [Потеря доступных имён при скрытии текста] → Использовать sr-only и проверять имена ссылок, tooltip и клавиатурный доступ.
- [Mobile после desktop-collapse] → Отдельно открыть Sheet при 390 px и проверить полные подписи и закрытие после перехода.

## Migration Plan

Миграции и изменения данных не нужны. Обычный merge в staging, CI и визуальная приёмка root; откат выполняется стандартным выпуском прежнего кода. Main и production в эту задачу не входят.
