# Проверка

Локальная ветка `bugfix/269` основана на staging `1924fb0a`. Сгенерирован клиент Prisma по схеме этой ветки. Проверка типов CRM, сборка бота, 48 тестов бота и 1690 веб-тестов прошли. OpenSpec strict и проверка diff прошли.

Тесты покрывают молчание непривязанного чата при сообщениях, нажатии старых кнопок, неверном коде и сбое проверки доступа. Также проверены точный отказ при нехватке прав, вход по подписанному запуску, отзыв привязки, отсутствие формы пароля и закрытие страниц, действий и файлов без Telegram-сессии.

Caddy разобрал конфигурацию отдельного staging-адреса. Настройки работающего Caddy и DNS не менялись. Для приёмки нужны обновлённые CRM и бот на staging, TLS нового адреса и проверка входа, открытие реестра и скачивание документа в настоящем Telegram. Порядок выпуска описан в [инструкции бота](../../../deploy/telegram-bot/README.md).
