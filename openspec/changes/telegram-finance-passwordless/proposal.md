# Proposal

## Why

Staging запрашивает пароль стенда до загрузки Mini App. Финансовое приложение также предлагает отдельный парольный сценарий для непривязанных чатов.

## What Changes

- Бот принимает действующую привязку CRM или одноразовый код, выданный из профиля CRM. Непривязанным чатам без действующего кода бот молчит.
- Mini App использует подписанный запуск Telegram и существующую привязку. Парольная привязка внутри Mini App удаляется.
- Бот получает права разделов из CRM. Финансовые экраны Mini App и команды бота используют существующие функции CRM.
- Для staging готовится отдельный HTTPS-адрес Mini App с проверкой Telegram-сессии.

## Capabilities

### New Capabilities

- `telegram-finance-passwordless` — вход по существующей привязке CRM и отказ в доступе к Telegram-разделам.

### Modified Capabilities

Парольный сценарий из изменений `telegram-finance-workspace` заменяется входом по привязке. Одноразовая ссылка из профиля CRM остаётся способом первичной привязки.

## Impact

Telegram-бот, API привязки и сессии, правила доступа CRM и конфигурация входа staging Mini App. Используется действующая схема привязок.
