# Proposal

## Why

Инженер сейчас получает стоимость изделия через OFFICE_ROLES; часть назначенных полевых сотрудников получает её в DTO. Сборщики и монтажники читают только ограниченную часть изделий после проектирования. Пользователь утвердил исправление91 и сохранение инженерного доступа DESIGN/PRODUCTION.

## What Changes

- Единое право финансового просмотра для менеджмента/финансовых ролей; исполнителям выдаются только их процентные суммы, без цены/процента/чужой оплаты.
- WORKER/MOUNTER читают все живые не-DESIGN изделия; назначение продолжает определять технические writes и свои суммы.
- Защита серверных вложенных DTO, списков, поиска и прямых ссылок; навигация доступна обеим полевым ролям.

## Capabilities

### New Capabilities

- `product-payment-privacy`: свои суммы, удаление коммерческих данных из DTO и чтение не-DESIGN изделий полевыми ролями.

### Modified Capabilities

- `engineer-product-access`: текущие назначенные DESIGN/PRODUCTION и скрытая стоимость доступных изделий в родительском проекте.

## Impact

Visibility/projections, product/project pages, task payment projections, navigation и тесты; миграция не нужна. Существующие финансовые права при совмещении сохраняются без расширения технических writes. Номера91 и ветка bugfix/91 согласованы.
