# Proposal

## Why

Задача 101 согласованного плана: экономика уже учитывает складские движения, но таблица расходов показывает только платежи. Пользователю нужны проверяемые строки и статьи, совпадающие с итогом проекта.

## What Changes

- Единая доменная проекция ProjectExpenseRow для денежных расходов, выдач и возвратов со склада.
- Общая агрегация сохранённых сумм для журнала, статей и экономики проекта без дополнительного Payment.
- Просмотр исходной операции, количества, точной снимковой цены и сотрудника в финансовом контуре обоих экранов проекта.
- Отдельная маркировка неполной истории и сохранение ограничений финансовых ролей.

## Capabilities

### New Capabilities
- `project-expense-ledger`: единый журнал и статьи расходов проекта.

### Modified Capabilities
Нет.

## Impact

Серверный модуль finance, общая вкладка финансов, оба загрузчика проекта и тесты. Без миграции, изменения складских движений и кассовых проводок. Выпуск только на staging в рамках разрешения владельца.
