# Spec Delta

## Purpose

Механика авансов доступна внутри раздела финансов без отдельного пункта бокового меню и с сохранением ранее установленных финансовых прав.

## ADDED Requirements

### Requirement: Авансы находятся внутри финансов

CRM SHALL показывать вход «Авансы» на странице «Финансы» и SHALL открывать выдачу аванса по адресу `/finance/advances`. Боковое меню SHALL не содержать отдельного пункта авансов ни у одной роли.

#### Scenario: Финансовая роль открывает авансы

- **WHEN** бухгалтер, снабженец, администратор или директор открывает раздел «Финансы»
- **THEN** вход «Авансы» открывает существующую форму выдачи, а отдельного пункта авансов в боковом меню нет.

### Requirement: Перенос не расширяет денежные права

CRM MUST допускать к странице авансов только пользователей с финансовым полномочием ADMIN, DIRECTOR, ACCOUNTANT или PROCUREMENT с учётом объединения совмещённых ролей. Перенос MUST сохранять серверные денежные ограничения, историю и расчёт долга.

#### Scenario: Чистый менеджер использует прямой адрес

- **WHEN** пользователь только с ролью MANAGER открывает `/finance/advances` или `/advances`
- **THEN** форма выдачи аванса недоступна.

#### Scenario: Менеджер совмещает финансовую роль

- **WHEN** пользователь с MANAGER и ACCOUNTANT открывает `/finance/advances`
- **THEN** доступ разрешён на основании финансовой роли.

### Requirement: Старый адрес сохраняет совместимость

CRM SHALL переводить финансового пользователя со старого `/advances` на `/finance/advances`, не выдавая новых прав остальным ролям.

#### Scenario: Сохранённая ссылка финансового пользователя

- **WHEN** бухгалтер открывает ранее сохранённый адрес `/advances`
- **THEN** пользователь попадает на новую страницу авансов внутри финансов.
