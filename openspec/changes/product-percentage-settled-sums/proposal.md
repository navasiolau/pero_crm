# Proposal: суммы назначенным при любом статусе + скрыть фильтр инженеров

## Контекст

Приёмка staging показала два дефекта: (1) инженерный этап изделия 202.1 не показывает сумму даже назначенному инженеру — строка суммы рендерилась только в `DRAFT`, а этап уже вышел из него; пропущенное при переходе начисление не давало даже прогноза; (2) у инженера в изделиях и проектах остаётся фильтр «Инженеры», хотя он видит только свои изделия.

## Цель

Каждый закреплённый за изделием специалист SHALL видеть свою сумму при любом статусе изделия (DRAFT/SETTLED/SKIPPED_ONCE/PENDING_FX); в зарплату сумма записывается только сменой статуса (без изменений). Фильтр «Инженер» SHALL NOT показываться пользователям с ролью ENGINEER без менеджерской (комбинированные сохраняют).

## Non-goals

- Механика начислений, формулы, триггеры статусов — без изменений.
- Серверная фильтрация по инженеру не меняется (уже ограничена своими); убираем только визуальный контрол.
