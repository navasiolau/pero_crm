# Spec Delta

## Purpose

Восстановление выпуска договора: согласованное поведение редактора и серверной части КП с сохранением прав, истории и согласованности связанных данных CRM.

## ADDED Requirements

### Requirement: Восстановление выпуска договора

Система SHALL выпускать договор с приложениями атомарно, сохранять ручные реквизиты и показывать безопасную причину отказа; повтор UUID SHALL возвращать прежнюю операцию.

#### Scenario: Основной сценарий
- **WHEN** пользователь повторяет генерацию после тайм-аута
- **THEN** возвращается прежнее задание без повторного выпуска, а отказ объясняет следующий шаг
