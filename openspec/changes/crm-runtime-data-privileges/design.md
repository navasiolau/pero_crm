# Design

Миграция добавляет локальную для БД группу привилегий. Администратор отдельно выдаёт серверному LOGIN членство в группе; роль мигратора сохраняет владение схемой. Runtime проверяет эффективные привилегии до запуска worker. Добавляются гранты без переноса данных и смены паролей.

Физическое удаление допускается только для технических незавершённых вложений. Личный план и привязка Telegram сохраняются при удалении. Схема проверяет каскады и запрещает перевод готовых вложений в удаляемое состояние. SDK выдаёт узкий DTO чтения проекта. Команды допускаются только через доверенный доменный вход.
