## ADDED Requirements

### Requirement: Полномочия рабочего соединения

Рабочая роль PostgreSQL SHALL сохранять бизнес-записи и не владеть бизнес-объектами.

#### Scenario: Попытка удаления факта

- **WHEN** рабочая роль выполняет прямое удаление, каскадное изменение ключа, TRUNCATE или DDL над бизнес-данными
- **THEN** PostgreSQL отклоняет изменение

### Requirement: Безопасный вход плагинов

Плагин SHALL получать только явно разрешённые SDK-операции.

#### Scenario: Демо-плагин читает проект

- **WHEN** плагин объявил разрешение на чтение проекта
- **THEN** SDK возвращает DTO без клиента Prisma и необёрнутых запросов
