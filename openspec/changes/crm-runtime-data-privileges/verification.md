# Проверка №252

Локально прошли генерация Prisma, TypeScript, 16 тестов контекстов плагинов и 13 тестов guards существующего CI. OpenSpec strict и git diff --check предусматривают отдельную проверку. Живые БД и контейнеры этой задачей не изменялись.

В существующий native CI добавлено доказательство на PostgreSQL 17. После стандартной миграции создаётся синтетический LOGIN, проверяются подключение, эффективные гранты, чтение, INSERT/UPDATE, удаление незавершённого документа, rollback, запрет удаления бизнес-строк и опубликованного документа, DDL/TRUNCATE, смены роли и SECURITY DEFINER. Отдельная транзакционная фикстура проверяет, что опасная связь от разрешённого черновика отклоняется. Фактический CI-прогон PostgreSQL и приёмка существующего staging выполняются в интеграции. Рабочий режим до переключения запускается прежним способом.
Дополнение по штатному запуску. Для ограниченного staging предусмотрен тот же root init при обычном deploy и W07 recreate, со штатным Prisma и refresh grants. После него setpriv необратимо сбрасывает UID/GID, supplementary groups и capability sets. Защищённый секрет остаётся недоступным процессу web. Watcher выполняет тот же init в своём временном container до переключения web, использует immutable digest и постоянные Compose-файлы. Production по умолчанию сохраняет прежний путь.

Локально deployment guards 89 тестов, из них 2 штатных платформенных skip. Синтаксис Node/Python/shell и git diff --check пройдены. Native CI проверяет тот же образ на принадлежащих job PostgreSQL/MinIO, временно убирает один grant перед стартом и ожидает его восстановления и readiness. Live deploy и ночной refresh этой задачей не запускались.
