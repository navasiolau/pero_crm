# Proposal

## Why

Веб-процесс и код плагинов сейчас имеют более широкие полномочия с данными, чем требуют рабочие сценарии CRM.

## What Changes

- Раздельные роли PostgreSQL для приложения и миграций, проверка рабочей роли до включения.
- Рабочая роль не владеет данными и не выполняет бизнес-удаления, очистку таблиц и DDL.
- **BREAKING** SDK предоставляет ограниченное чтение и проверенные операции хоста. Плагины с произвольными запросами и событиями переходят на публичный контекст.

## Capabilities

### New Capabilities

- `crm-runtime-data-privileges`: ограничения доступа к данным на уровне PostgreSQL и плагинов.

### Modified Capabilities

## Impact

Prisma migrations, контур CI, запуск CRM, Plugin SDK и контексты.
