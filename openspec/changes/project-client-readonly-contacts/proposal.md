# Proposal
## Why
Карточка проекта редактирует общий телефон клиента и показывает адрес заказа вместо адреса выбранного клиента. Владелец требует единое чтение контактов клиента, как в карточке изделия.
## What Changes
- Выбор клиента сохраняется частичным CAS; телефон и адрес клиента показаны отдельными readonly строками под выбором.
- Повторно используется реальный диалог создания клиента и существующие права Client CRUD.
- Исторический Project.address, доставка и остальные поля проекта не изменяются вследствие выбора клиента.
## Capabilities
### New Capabilities
- `project-client-readonly-contacts`: подтверждённые контакты выбранного клиента в карточке проекта.
### Modified Capabilities
Нет.
## Impact
Project overview/provider/contacts DTO, существующий shared ClientDialog; без миграций и новых зависимостей. Обычные Client/Project CRUD сохраняются, карточка не создаёт controllers телефона/адреса.
