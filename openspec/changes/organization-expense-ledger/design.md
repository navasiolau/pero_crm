# Design

## Context

Nullable Payment поля и общий INCOME готовы ранее; Payment_project_direction_check разрешает NULL только INCOME. Документ и общая форма/DTO готовы в99.

## Goals / Non-Goals

**Goals:** обычный общий расход через прежний ledger, общие UI/query, явный контекст бота.
**Non-Goals:** автоматическое распределение общих расходов, новые виды зарплаты, изменение исторических валют/цен, складская закупка103.

## Decisions

1. Заменить старый CHECK на эквивалентность NULL projectId/projectAmount для обоих направлений. Строки не обновлять. Убрать только Zod project-required refine; live-project проверка при переданном ID остаётся.
2. loadOrganizationPayments читает направление с финансовым guard и общей paymentView; loadOrganizationIncome остаётся совместимым wrapper. expenseArticles загружает только страница расходов. Один OrganizationPaymentsView отображает оба журнала и детали строки.
3. В общей форме использовать SearchableSelect c номером проекта; пустой выбор явно подписан по направлению. Заголовок/пояснение общего расхода не обещают изменение маржи проекта.
4. В боте projectSelected отделяет «контекст ещё не выбран» от projectId=null. Нельзя пропустить шаг подделкой callback; общий контекст выводится одинаково в запросе суммы и подтверждении. Серверное ядро/документы/receipt не дублируются.
5. Инвалидация общих расходов/доходов следует одному платежному маршруту; document-required, cash/org caps и legacy NULL guards сохраняются.
6. Новый общий журнал сохраняет read-only историю архивных проектов. Признак archived передаётся безопасной проекцией; delete-core проверяет его заново в транзакции, чтобы общий список не расширял доступ относительно финансовой карточки проекта.

## Risks / Trade-offs

- Пропущенный проект и несуществующий ID различаются: отсутствие разрешено, переданный неверный/архивный ID отклоняется.
- Миграция ослабляет только прежний запрет общего EXPENSE, оставляет nullable пару. Возврат старого ограничения после появления общих расходов недопустим; rollback приложения сохраняет данные и новую совместимую схему.
