# Proposal

## Why

Инженер не может исправить документы чужого или завершённого изделия: загрузка связана с назначением и DESIGN, удаление — с автором файла. Владелец согласовал самостоятельные файловые права по этапу объекта, включая изображения и проекты «Отказ».

## What Changes

- Любой ENGINEER управляет общими файлами и обложкой проекта IN_WORK/DONE/REFUSED; CONTRACT остаётся доступен для чтения.
- Файлы и эскиз изделия DESIGN/PRODUCTION/STORAGE/INSTALLATION/DONE редактируются при доступном родителе, независимо от назначения и автора.
- Вложения задач проверяются по согласованности связей, без требования назначения инженера исполнителем.
- Файловые разрешения отделяются от технических, финансовых и исполнительских прав; совмещённые роли сохраняют самостоятельные grants.
- Сервер повторно проверяет права при сохранении, сохраняя аудит, replay и защиту конфликтов.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `engineer-product-access`: самостоятельное управление техническими файлами и видимость REFUSED.

## Impact

Политики файлов, загрузка/удаление, изображения проектов/изделий, карточки и существующие тесты. Форматы upload/delete команд сохраняются. Миграция статусов — отдельная задача bugfix/209. Коммиты, main и production отдельно не разрешены.
