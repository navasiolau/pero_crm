# Spec Delta

## ADDED Requirements

### Requirement: Точный числовой ввод
Система SHALL показывать подпись «Процент инженера, %», ширину ENGINEERING 192px с ограничением шириной контейнера, внутренние стрелки и принимать только ASCII цифры и точку с двумя дробными знаками. Стрелки SHALL менять draft точно на 0.1, ограничивая 0–100, и сохранять через текущий CAS/UUID-controller. Пустое поле SHALL сохранять NULL, явный 0 SHALL сохранять нулевую ставку.

#### Scenario: Шаг и потерянный ответ
- **WHEN** пользователь увеличивает 5.05 и ответ сохранения теряется
- **THEN** значение равно 5.15, повтор использует тот же UUID и baseline

#### Scenario: Запрещённые символы
- **WHEN** пользователь вводит e, E, знак, запятую или третью дробную цифру
- **THEN** draft не принимает такой ввод

### Requirement: Скрытый исторический результат
Система SHALL не отображать блок «Сохранённый результат этапа» для ENGINEERING, ASSEMBLY и INSTALLATION; финансовые снимки, права и retry SHALL оставаться прежними.

#### Scenario: Исторический этап
- **WHEN** открыта карточка с защищённым либо начисленным этапом
- **THEN** исторический блок отсутствует, текущие поля используют прежние права
