# Proposal

## Why

Поле процента инженера слишком узкое и допускает неподходящий ввод. Владелец утвердил точный шаг и удаление блока исторического результата.

## What Changes

- Подпись «Процент инженера, %», ширина 192px с адаптивным ограничением.
- Только ASCII цифры и точка; внутренние стрелки шага 0.1 с границами 0–100.
- Удалить блок сохранённого результата всех трёх этапов.

## Capabilities

### New Capabilities
- `engineer-percentage-input`: управляемый числовой ввод ставки через существующий CAS-controller.

### Modified Capabilities
Нет.

## Impact

SinglePercentageRow, небольшой компонент/числовой helper и frontend controller. Денежные записи и серверные правила не меняются.
