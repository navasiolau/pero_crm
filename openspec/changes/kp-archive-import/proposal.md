# Proposal

## Why

Задача №189 переносит существующие КП и договоры в CRM с проверяемым manifest и сохранением бизнес-данных. Уточнение владельца от 26.10.2026 отменяет отдельный архивный режим: перенесённые 23 КП должны работать по общим правилам КП и этапа связанного проекта. Сам перевод не должен синхронизировать или менять вручную отредактированные проекты, изделия и клиентов.

## What Changes

- Read-only discovery исходных JSON, изображений и DOCX; фиксированный manifest с SHA-256, датами, связями, confidence и явными неизвестными.
- Обычные КП без отдельного архивного флага поведения, фильтра API и блокировки редактора. Источник, неизвестные поля и исходные JSON-байты сохраняются как история импорта.
- Проверенная привязка перенесённых КП к уже существующим проектам с совпадающим номером; сохраняются состояния, ревизии, даты, версии, изображения и DOCX. Не создаются проекты, изделия и клиенты, не вызывается обычное сохранение/пересчёт КП.
- Точные существующие номера изделий могут связываться только через ProposalItem; неподтверждённые соответствия не угадываются. Поля самих Product не изменяются.
- Открытие КП не вызывает PUT или синхронизацию; явное сохранение разрешено только в «Лиде». Генерация PDF фиксирует версию отдельно. Первое явное сохранение ранее не имевшего курса КП может получить обычный курс НБРБ на дату КП; существующий курс не обновляется автоматически.
- PENDING ledger и настоящие UPLOAD_MEDIA jobs до I/O, подтверждённый readback, leases и единая транзакция публикации всего архива.
- Dry-run CLI по умолчанию; apply только по reviewed manifest и guards существующих local5433/staging либо отдельному явно разрешённому production release proof с точной runtime/DB/storage binding.
- Документ переключения после приёмки с сохранением старого R2; глобальный флаг не включается автоматически.
- По явному решению владельца: восстановление отсутствующих изображений из проверенных локальных файлов/PDF через отдельный reviewed portable map. Источник сначала проверяется настоящим GET, исходный URL и provenance сохраняются; это не заявление об оригинальных отсутствующих R2-байтах.

## Capabilities

### New Capabilities

- `kp-archive-import`: историческое имя возможности проверяемого импорта КП и договоров; отдельного пользовательского архивного режима больше нет.

### Modified Capabilities

Нет.

## Impact

Серверный importer, read-only R2 adapter, CLI и собственные тесты. Зависимости №180/183/185/186/187 интегрируются обычными merge; существующий генератор, его незакоммиченный договор и исходные хранилища не изменяются. Исторический ориентир 23/189/6/7 не объявляется свежей инвентаризацией.
