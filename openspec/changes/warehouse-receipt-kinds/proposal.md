# Proposal

## Why

Задача 102 согласованного плана: существующий «Приход» меняет только склад, что не позволяет отличить инвентарное поступление от закупки за деньги. Требуется явная классификация без догадок о прошлых операциях.

## What Changes

- Добавить виды складского прихода: INVENTORY и PAID; для прежних записей сохранить неизвестный вид.
- Назвать текущую безденежную форму «Инвентарный приход», явно показать отсутствие кассового расхода.
- Сохранять вид нового инвентарного прихода и показывать/фильтровать его в журнале.
- Подготовить общий доменный контракт; оплаченный приход проводится атомарной операцией задачи 103, произвольный paid-флаг обычной форме запрещён.

## Capabilities

### New Capabilities
- `warehouse-receipt-kinds`: достоверное различие поступлений и их отображение.

### Modified Capabilities
Нет.

## Impact

Аддитивная Prisma-миграция без обновления истории, складское ядро, форма и журнал. Зависимость для 103. Staging разрешён, main ожидает владельца.
