# Proposal

## Why

Ошибочный рейс необходимо убрать из рабочих списков и учёта с сохранением исходной истории. Такое действие должно быть доступно только администратору и отменять влияние целого рейса одной подтверждённой операцией.

## What Changes

- Добавить мягкое удаление рейса с автором, временем, аудитом и защитой повторов.
- Исключать его расходы из всех денежных расчётов через общий фильтр.
- Добавить ADMIN-кнопку с подтверждением и закрыть чтение, файлы и изменения удалённых рейсов.

## Capabilities

### New Capabilities

- `logistics-trip-soft-delete`: безопасная отмена целого рейса администратором с сохранением истории.

### Modified Capabilities

Нет опубликованной основной спецификации логистики. Исходные требования сохранены в changes №123–125.
