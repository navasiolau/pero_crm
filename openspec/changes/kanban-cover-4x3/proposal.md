# Proposal

## Why

Владелец согласовал для обложек канбана горизонтальную область 4:3 вместо действующей 3:4. Единая геометрия нужна в проектах, изделиях и изделиях внутри проекта без изменения просмотра исходных изображений.

## What Changes

- Обложки двух общих канбан-карточек становятся горизонтальными 4:3 с центрированным `object-cover`.
- Сохраняются устойчивый размер при загрузке и ошибке, компактность карточек без обложки, навигация и запрет клика при перетаскивании.
- Существующий объединённый браузерный сценарий получает актуальную геометрию и скриншоты; поиск проверяется прежним реальным React/Chromium-сценарием.
- Детальные карточки проектов/изделий, полноэкранный просмотр, оригиналы файлов и общий fallback `ProductHeroImage` сохраняют текущее поведение.

## Capabilities

### New Capabilities

- `kanban-cover-4x3`: горизонтальные обложки 4:3 во всех канбан-контекстах и их устойчивость при загрузке, ошибке и DnD. Заменяет прежнее согласование 3:4 из change `kanban-cover-3x4`, ещё не перенесённого в основные specs.

### Modified Capabilities

Нет: среди основных specs отсутствует capability обложек канбана.

## Impact

Меняются только геометрия в `ProjectKanbanCard` / `ProductKanbanCard` и относящиеся к ней существующие browser-сценарии. API, БД, роли, зависимости и форматы оригинальных файлов не меняются. Задача №176, ветка `feature/176`; коммиты и staging-приёмка выполняются отдельно оркестратором.
