# Proposal

## Why

В задаче 145 ProductsKanban создаёт отдельный массив разрешённых строк через filter(), но запускает переход к точному номеру только при products === initialProducts. Условие всегда ложно: уже согласованный поиск точного номера изделия не прокручивает экран к карточке.

## What Changes

- Связать готовность отображённых строк с конкретным применённым серверным ответом и ролями; отфильтрованный массив не используется как идентификатор ответа.
- Сохранить подтверждение полного query, завершённого pending и черновика поиска во View; не запускать переход во время DnD, открытой панели фильтров либо оптимистичного изменения до нового серверного ответа.
- Добавить воспроизводящий regression на настоящем React/Chromium и проверить однократную прокрутку, поздние ответы, отсутствие совпадения, ручную прокрутку и caret.
- Сохранить компоновку, роли, фильтры, CAS, несохранённый ввод, навигацию и действующую семантику статусов. Ожидаемое видимое отличие — восстановленная прокрутка к точному номеру.

## Capabilities

### New Capabilities

- `kanban-identity-search-focus`: уточнить применение актуальных разрешённых строк в канбане изделий. Путь переиспользуется из принятого change kanban-identity-search-focus; в текущем каноническом inventory этой спецификации ещё нет. Область поиска, правила доступа и существующая однократность не расширяются.

### Modified Capabilities

Нет. Канонический persistent-list-state сохраняет действующие URL, приоритет сохранения и серверный CAS без изменений.

## Impact

Один production consumer: apps/web/src/app/(app)/products/products-kanban.tsx. Целевой компонентный regression и существующие query/page/browser проверки канбана; общий useKanbanSearchFocus и ProjectKanban не изменяются. Нет изменений БД, денежных расчётов, server actions, dependencies, CSS либо task128 actor-контекста. Ветка bugfix/145 от origin/staging cd38cb745759becd58dbbad4d6d37afa03f0ab7a, отдельная от reviewed WIP128. Реализация после согласования дизайна; коммиты остаются HOLD до явного разрешения владельца, main/production запрещены.
