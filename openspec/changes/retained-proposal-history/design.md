# Design

У опубликованных изображений и документов сохраняются прежние состояния, связи, идентификаторы и контрольные суммы. Планировщик и авторитетная проверка исключают опубликованные объекты из очистки. Отменённые старые задания сохраняют прогресс для проверки существования байтов.

Текущие связи изображений скрывают снятые фотографии из результата текущей редакции. Версии сохраняют собственные связи. Синхронизация изделия сохраняет отозванные копии отдельно от действующего списка и возвращает подходящую копию после подтверждения новой редакции.
