# Spec Delta

## Purpose

Сотрудник печатает выбранный доступный PDF или изображение из списка вложений средствами браузера, без печати интерфейса CRM и без изменения оригинального файла.

## ADDED Requirements

### Requirement: Доступные форматы печати

Система SHALL показывать маленькую кнопку принтера перед удалением для PDF и поддерживаемых браузером изображений. Кнопка SHALL иметь доступное русское название, не запускать действие строки и быть скрыта для остальных форматов.

#### Scenario: PDF и изображение
- **WHEN** в списке находится PDF, PNG или JPEG
- **THEN** рядом с названием присутствует отдельная кнопка печати выбранного вложения

#### Scenario: Неподдерживаемый документ
- **WHEN** строка содержит DOCX, B3D, DWG, XLSX, видео или неподдерживаемый тип изображения
- **THEN** кнопка печати отсутствует, а клик по названию сохраняет поведение задачи 115

### Requirement: Только защищённый оригинал

Система MUST получать оригинал из известного защищённого маршрута проекта или финансового документа с текущей авторизацией. Отказ доступа, пустой ответ, HTML страницы входа, неверный MIME и некорректный PDF SHALL завершаться понятной ошибкой без вызова печати.

#### Scenario: Право отозвано после показа строки
- **WHEN** защищённый маршрут возвращает 401, 403 или 404
- **THEN** диалог печати не вызывается и сотрудник получает сообщение о недоступности файла

#### Scenario: Разные источники
- **WHEN** печатается проектное или финансовое вложение
- **THEN** используется соответствующий защищённый маршрут и сохраняются оригинальные байты файла

### Requirement: Печать документа без интерфейса CRM

Система SHALL вызывать штатную печать браузера только для выбранного PDF либо целого изображения после загрузки. Изображение MUST сохранять пропорции, отображать все края и не использовать обрезку канбана 3:4. PDF MUST передаваться штатному просмотрщику браузера без HTML-заглушки или новой библиотеки.

#### Scenario: Полное изображение
- **WHEN** печатается высокий, широкий или квадратный эскиз
- **THEN** в печати видно целое изображение без элементов CRM и без обрезки

#### Scenario: PDF
- **WHEN** оригинальный PDF успешно загружен и браузерный PDF-контекст готов
- **THEN** открывается штатный диалог печати PDF, а не страницы списка файлов

### Requirement: Подготовка и очистка печати

Система SHALL блокировать повторный запуск во время подготовки, поддерживать отмену подготовки и ограничивать время загрузки. После завершения или отмены печати ресурсы SHALL удаляться по штатному событию, при уходе со страницы, следующем задании либо по ограниченному таймауту. Одновременно SHALL существовать не более одного печатного iframe.

#### Scenario: Повторный клик
- **WHEN** сотрудник повторяет нажатие до завершения загрузки документа
- **THEN** создаётся только одно задание и кнопка остаётся неактивной во время подготовки

#### Scenario: Отмена или сбой
- **WHEN** сотрудник отменяет подготовку, загрузка завершается ошибкой или истекает таймаут
- **THEN** печать не запускается и временные iframe, blob и обработчики удаляются

#### Scenario: Асинхронная native PDF печать
- **WHEN** браузер возвращает управление из PDF print без внешнего afterprint
- **THEN** документ сохраняется для браузерной печати и удаляется при следующем задании, уходе со страницы либо через ограниченный таймаут
