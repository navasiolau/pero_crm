# Proposal

## Why

Сотруднику нужна печать выбранного вложения прямо из компактного списка файлов. Печать должна передавать браузеру сам документ, сохраняя оригинальное изображение и доступ через защищённые маршруты CRM.

## What Changes

- Добавить маленькую кнопку принтера для PDF и изображений, поддерживаемых браузером, перед кнопкой удаления.
- Печатать только выбранное вложение без интерфейса CRM и без обрезки изображения.
- Проверять ответ защищённого маршрута до запуска печати; обрабатывать отказ доступа, ошибку загрузки, отмену и очистку ресурсов.
- Запретить повторную подготовку одного задания, пока браузер занят печатью.
- Для DOCX, CAD, таблиц, видео и других форматов кнопку не показывать; клик по названию остаётся поведением задачи 115.

## Capabilities

### New Capabilities

- `browser-file-print`: браузерная печать доступного PDF или полного оригинала изображения из общего списка вложений.

### Modified Capabilities

Нет.

## Impact

Новый клиентский helper и отдельная кнопка печати; после интеграции задачи 115 — подключение к общей файловой строке проектов, изделий, задач и финансовых вложений. Новых пакетов, преобразования форматов, PDF-библиотек, изменений схемы БД и серверных прав не требуется. Задача 116, ветка feature/116; commit/push/merge выполняет оркестратор после прямого разрешения владельца.
