# Spec Delta

## Purpose

Обеспечить согласованное изменение интерфейса и поведения задачи78 с проверяемыми сценариями, сохранением действующих прав и совместимостью с существующими данными.

## ADDED Requirements

### Requirement: Компактный процентный блок

Три блока изделия SHALL показывать процент и сумму слева, специалиста справа, с ширинами до144/240px и сжатием без горизонтального выхода за экран.

#### Scenario: Длинное имя
- **WHEN** выбран специалист с длинным ФИО на360px
- **THEN** поле помещается, полное имя доступно в списке

#### Scenario: Три специалиста
- **WHEN** открыты ENGINEERING/ASSEMBLY/INSTALLATION
- **THEN** в каждом процент слева, специалист справа

### Requirement: Читаемая сумма

При прежних состояниях/правах суммы система SHALL показывать «Сумма: 50 BYN» без предварительных/приблизительных слов, 18px полужирным цветом темы; null SHALL показываться«Сумма: —».

#### Scenario: Подтверждённая сумма
- **WHEN** расчёт дал50BYN
- **THEN** показана строка«Сумма: 50 BYN»

#### Scenario: Неполные поля
- **WHEN** для расчёта недостаточно подтверждённых данных
- **THEN** показана«Сумма: —», прежние ошибки/сохранение доступны
