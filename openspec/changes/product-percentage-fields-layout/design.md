# Design

## Context

SinglePercentageRow содержит растянутого специалиста слева, ставку192px справа и малозаметный DRAFT результат ниже. Подтверждённые controller baselines уже обеспечивают правильный момент обновления.

## Goals / Non-Goals

**Goals:** компактные две колонки и читаемая сумма.
**Non-Goals:** возврат скрытого исторического блока, изменение видимости финансов/контроллеров.

## Decisions

В существующей строке процент слева max144px с устойчивой шириной на телефоне; под ним условная DRAFT/canViewAll сумма. Короткая подпись «Процент, %» и aria-label группы определяют специалиста; поля выровнены по высоте. Специалист справа max240px и min-w-0; flex-shrink допускает360px. Итог text-[18px], font-semibold/tabular-nums/text-primary; текст «Сумма: {formatAmount(total,...)}», null→«Сумма: —». Использовать уже рассчитанный итог: точный ceil обеспечивает отдельный change77. Удалить старую строку preview. Ошибки/статусы/обработчики и выбор сотрудника прежние. Для внутренних стрелок ввода отменить общий mobile минимум44px, чтобы две стрелки помещались в поле и не перекрывали сумму; основной input/selector сохраняют48px.

## Risks / Trade-offs

Длинное имя → прежний searchable dropdown показывает полностью, triggertruncate. Число/подпись → break-words и min-w-0; проверка360/390/1440 в обеих темах. Соседняя77 меняет versiondefault в другой части функции, обычный merge сохраняет оба изменения.
