# Design

## Context

См. proposal.md. Реальный AppShell использует inset-панель с наружными 8 px в expanded и 0 px в collapsed. В обоих состояниях SidebarHeader имеет p-2. Брендовая кнопка size lg даёт 48 px в expanded и принудительные 32 px в collapsed. SiteHeader сохраняет верхнюю позицию и высоту при переключении.

Измерено до изменения в actual AppShell/SiteHeader при 1440 и 1024 px: центр пера 40/24 px, кнопки 31,5 px; скачок пера составляет 16 px. Root подтвердил эти значения на действующем staging.

## Goals / Non-Goals

**Goals:** одинаковая вертикальная геометрия бренда в двух desktop-состояниях, минимальное изменение текущего компонента.

**Non-Goals:** изменение глобального Sidebar, SiteHeader, ширины rail, навигации, ролей, данных и мобильных размеров.

## Decisions

- В AppSidebar задать брендовой кнопке md:h-8. Центр expanded становится 8 px наружного поля + 8 px header + 16 px кнопки = 32 px. Мобильная высота lg 48 px сохраняется.
- В collapsed-состоянии увеличить верхний отступ только брендового SidebarHeader до 16 px: 0 + 16 + 16 = те же 32 px. Desktop group-data отсутствует у мобильного Sheet, поэтому мобильный header не меняется.
- Сохранить текущие sr-only, aria-label и горизонтальное центрирование. Перенос расчёта в общий Sidebar или изменение SiteHeader затронуло бы несвязанные компоненты.
- Проверять настоящие AppShell/AppSidebar/SiteHeader с Tailwind в приватной browser-обвязке; не добавлять постоянный тест, повторяющий две строки CSS. Root отдельно принимает фактический staging.

## Risks / Trade-offs

- [Округление границы SiteHeader] → Сравнивать центры с допуском 1 CSS px; фактический центр кнопки 31,5 px из-за нижней границы header.
- [Размер кнопки на телефоне] → Ограничить новую высоту префиксом md; отдельно проверить 360/390 px и способы закрытия Sheet.
- [Переопределение important collapsed-классов] → Измерять bounding boxes после переключения и Ctrl+B, а не считать исправление доказанным по тексту классов.

## Migration Plan

Миграции не нужны. Обычный merge в staging, штатный CI, root проверяет actual SHA/образ/health и повторяет геометрию. Откат — стандартный выпуск прежней версии компонента. Production/main в эту задачу не входят.
