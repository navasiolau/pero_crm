# Spec Delta

## Purpose

Журнал позволяет восстановить изменения работ, задач, их распределения и вложений по полным сохранённым значениям и точным владельцам событий.

## ADDED Requirements

### Requirement: Полные значения операций

Работы, задачи, распределения и файлы MUST сохранять полные доступные значения создания, изменения и удаления. Снимок SHALL включать исполнителей, сроки, объёмы, цены, единицы, зависимости и файловые метаданные, когда операция их затрагивает.

#### Scenario: Изменение работы и загрузка файла
- **WHEN** меняются расценка и объём работы либо загружается файл задачи
- **THEN** журнал содержит полные до/после работы и имя, тип, размер, раздел и принадлежность файла.

### Requirement: Контексты на момент изменения

Событие MUST сохранять принадлежность на момент операции. Обычный объект изделия SHALL попадать только в журнал изделия; общепроектный — в журнал проекта. Перенос MUST отражаться в журналах прежнего и нового владельца.

#### Scenario: Перенос задачи
- **WHEN** общепроектная задача переносится в изделие или между изделиями
- **THEN** сохранённое событие доступно у всех непосредственно затронутых владельцев, без подстановки будущих связей.

### Requirement: Системные последствия и атомарность

Автоматическое начисление, перенос начисления и отвязка файлов MUST отображаться от «Системы» с инициатором. Изменения и обязательный аудит SHALL коммититься вместе, а повторы подтверждённых UUID SHALL не дублировать события.

#### Scenario: Отказ журнала при удалении задачи
- **WHEN** запись аудита удаления отказывает
- **THEN** задача, связи, файлы и их аудит остаются в прежнем состоянии.
