## Regression fix

Root local runtime review обнаружил, что на общей доске `<img>` мог завершить неуспешный запрос до hydration: DOM уже показывал `complete=true`, `naturalWidth=0`, `naturalHeight=0`, но React `onError` не срабатывал и заглушка не появлялась. `ProductHeroImage` после hydration теперь читает только текущий `<img>` с тем же `src` и распознаёт именно `complete && naturalWidth === 0`. Incomplete image с нулевой шириной остаётся в загрузке; завершённая image с положительной шириной не становится ошибкой. `onError` остаётся для позднего отказа, а другой `src` не наследует прежнюю ошибку.
