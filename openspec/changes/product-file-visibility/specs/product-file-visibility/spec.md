# Spec Delta

## Purpose

Дать цеху и монтажникам доступ на чтение ко всем файлам изделий, вышедших из проектирования, сохраняя закрытым статус DESIGN и без расширения записи.

## ADDED Requirements

### Requirement: Видимость файлов не-DESIGN изделий для цеха и монтажников

Система SHALL предоставлять пользователю с ролью WORKER или MOUNTER чтение всех файлов изделия со статусом не DESIGN: прямые файлы изделия (замеры MEASUREMENT, документы производства и монтажа, файлы инженера), эскиз sketchFile, признак .b3d hasB3d, счётчик файлов и файлы задач этого изделия. Проверка SHALL использовать тот же fileVisibilityWhere для списков файлов, эскиза, hasB3d, _count.files, файлов задач и скачивания /api/files/:id.

#### Scenario: Цех видит файлы чужого изделия в PRODUCTION

- **WHEN** WORKER без назначения на изделие запрашивает карточку изделия PRODUCTION, список файлов, эскиз, hasB3d или скачивание /api/files/:id для замера, эскиза и документа этого изделия
- **THEN** система возвращает файлы, эскиз, hasB3d=true, счётчик включает эти файлы, а скачивание отдаёт содержимое вместо 404

#### Scenario: Монтажник видит файлы задач не-DESIGN изделия

- **WHEN** MOUNTER без назначения на задачу запрашивает файлы задачи, привязанной к изделию PRODUCTION (прямо через productId или косвенно через task.product)
- **THEN** файлы задачи доступны на чтение в карточке изделия, в файлах проекта и через /api/files/:id

#### Scenario: Эскиз и .b3d покрываются тем же правилом

- **WHEN** WORKER или MOUNTER открывает изделие PRODUCTION с эскизом и .b3d-файлом чужого назначенного изделия
- **THEN** sketchFile возвращается через productSketchProjection, hasB3d=true через тот же fileVisibilityWhere с фильтром .b3d, без отдельных правил

### Requirement: Статус DESIGN остаётся закрытым

Система SHALL скрывать от неназначенных WORKER и MOUNTER все файлы изделия со статусом DESIGN: прямые файлы, эскиз, .b3d, счётчики и файлы задач DESIGN-изделия недоступны и скачивание возвращает 404.

#### Scenario: Цех не видит файлы DESIGN

- **WHEN** WORKER или MOUNTER без назначения на DESIGN-изделие запрашивает его файлы, эскиз, hasB3d или скачивание
- **THEN** списки пусты, эскиз null, hasB3d=false, счётчик не учитывает скрытые файлы, скачивание возвращает 404

#### Scenario: Назначенные файлы DESIGN сохраняются

- **WHEN** WORKER или MOUNTER имеет назначение на DESIGN-изделие (сборщик, монтажник, задача, процент INSTALLATION)
- **THEN** прежние назначенные права продолжают работать без изменений

### Requirement: Только чтение без расширения записи и цен

Система SHALL не расширять загрузку, удаление, правку эскиза и видимость цен: upload-context, delete-permission, cover-core, canEdit/canReplaceProductCover и maskProductionRead остаются без изменений.

#### Scenario: Загрузка и удаление как были

- **WHEN** WORKER или MOUNTER пытается загрузить файл в чужое не-DESIGN изделие без своей задачи или удалить чужой файл
- **THEN** операция отклоняется по прежним правилам, хотя чтение этих файлов разрешено

#### Scenario: Правка эскиза и цены закрыты

- **WHEN** WORKER или MOUNTER открывает чужое не-DESIGN изделие
- **THEN** canEdit/canReplaceProductCover остаётся false, описание и цены маскируются по прежнему maskProductionRead
