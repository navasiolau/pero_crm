# Проверка №241

Проверены типы web, strict OpenSpec и 27 тестов финансового учёта, документов и Журнала. Тот же сценарий, который включён в штатный PostgreSQL integration suite, выполнен на существующей локальной базе 5433 после миграции. Сохранены оба документа в исходном порядке, ID платежа, дата, курс и 30,75 BYN. Отказ при недостаточном остатке оставил Журнал прежним. Повтор вернул ту же квитанцию, откат отката восстановил баланс. Внешняя проверочная транзакция отменена целиком.
