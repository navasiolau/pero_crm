## Context

Физическая версия меняется при любой правке поля. После штатной отмены предыдущая правка может снова стать доступной.

## Decisions

- PostgreSQL-триггер фиксирует фактические изменения поля. Прежний titleRevision сохраняется.
- Команда отката указывает, к какой логической версии вернулось поле. История старого отката названия читается по его ссылке на исходное событие.
- Сравнивается только нужное поле или доменная группа. Используются штатные проверки и числовые расчёты.

## Risks / Trade-offs

Сторонние правки без подтверждённой обратной команды прерывают цепочку. Неполная история остаётся доступной для просмотра.
