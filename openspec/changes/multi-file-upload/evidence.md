## Ручные кейсы (к local/staging приёмке, обязательны)

1. Shift-выбор 5–20 фото одной пачкой во вкладке файлов → итог «Загружено N из N»,
   каждая с thumb; превью (WebP) открывается, удаление работает.
2. Пачка с одним изображением >25 МБ среди валидных → отказ только этого файла,
   остальные загружены, итог «Загружено X из Y» + строка «имя: Файл больше 25 МБ».
3. Документ PDF ~600 МБ → принимается; изображение того же размера → 413 про 25 МБ.
4. Одиночная обложка проекта и эскиз изделия — как раньше (один файл, те же проверки).
5. Выбор >100 файлов → загружаются первые 100 + сообщение об усечении.

## Риск (зафиксирован)

`Buffer.from(await file.arrayBuffer())` + одиночный `s3Put` держат весь файл в памяти
Node. Крупные файлы идут строго последовательно (не параллельно), но local/staging
тест PDF ~600 МБ–1 ГБ обязателен до приёмки: смотреть память процесса и отсутствие
OOM. Потоковая запись в S3 — вне scope, follow-up при проблемах.
