# Proposal

## Why

Стрелка из карточки изделия появилась только на пяти других экранах. Возврат из остальных разделов выглядит и работает по-разному.

## What Changes

Все рабочие страницы используют общий заголовок с одной стрелкой. Родители вложенных страниц и история разделов определяются централизованно. Начальная страница роли скрывает стрелку при первом входе.

## Capabilities

### New Capabilities

- `crm-page-navigation` — контекстный возврат между рабочими страницами CRM и финансового Mini App.

## Impact

Заголовки приложения, клиентская навигация и проверки маршрутов. Согласованный объём соответствует ветке `bugfix/266`.
