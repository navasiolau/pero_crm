# Design

## Context

Для изделия и проекта уже существуют проверенные адреса возврата. Стрелку выводит PageBackLink. Роль определяет стартовую страницу через homePathForRoles.

## Decisions

PageHeader собирает кнопку, заголовок, описание и действия. Страница может передать готовый контекстный адрес. Общая оболочка отслеживает адреса открытых экранов во вкладке и восстанавливает их при переходах браузера. Настройки списка относятся к одному экрану. Финансовый Mini App использует собственный контекст навигации.

## Risks / Trade-offs

При прямом входе доступен проверенный родитель или стартовый экран. Параметризованная проверка сравнивает реальные маршруты с инвентарём приложения. Отдельный браузерный сценарий проверяет обе координаты канбана.
