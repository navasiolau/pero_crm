# Spec Delta

## Purpose

Инициализация подписи КП: согласованное поведение редактора и серверной части КП с сохранением прав, истории и согласованности связанных данных CRM.

## ADDED Requirements

### Requirement: Инициализация подписи КП

Система SHALL один раз заполнять подпись, должность, телефон, гарантию и подвал при создании КП через UI/API, сохраняя явно переданные поля и повторяемость UUID.

#### Scenario: Основной сценарий
- **WHEN** создаётся КП либо открывается прежнее КП
- **THEN** новое получает сохранённые defaults, повтор UUID возвращает прежний снимок, прежние КП не перезаписываются
