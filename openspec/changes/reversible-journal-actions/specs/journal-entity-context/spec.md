## ADDED Requirements

### Requirement: Журнал проекта последней вкладкой

Страница проекта SHALL показывать последнюю вкладку «Журнал» администратору и директору. Данные SHALL запрашиваться при открытии вкладки по постоянному ID проекта.

#### Scenario: Прямой вход

- **WHEN** администратор или директор открывает карточку проекта с `tab=journal`
- **THEN** отображается журнал этого проекта

### Requirement: Журнал изделия нижней секцией

Страница изделия SHALL показывать нижнюю секцию «Журнал» администратору и директору. Данные SHALL загружаться при появлении секции в области просмотра по постоянному ID изделия.

#### Scenario: Изделие открыто по номеру

- **WHEN** директор открывает изделие по номеру и прокручивает до секции журнала
- **THEN** журнал загружается по постоянному ID изделия

### Requirement: Единый интерфейс и изоляция контекста

Контекстные журналы SHALL использовать общий интерфейс журнала в точном контексте исходного проекта или изделия. Сервер SHALL проверять роль администратора или директора до чтения.

#### Scenario: Сброс фильтра

- **WHEN** директор сбрасывает фильтры в карточке
- **THEN** запрос остаётся в контексте этой карточки

### Requirement: Отсутствие доступа у остальных ролей

Страницы MUST исключать журнал для пользователей без роли администратора или директора. Серверный запрос чтения MUST отклоняться до чтения журнала.

#### Scenario: Остальные роли

- **WHEN** менеджер открывает карточку, к которой имеет доступ
- **THEN** карточка не содержит компонента и данных журнала
