## Context

ChangeLog хранит представление событий и durable receipts. Снимки отображения не задают команду обратной записи.

## Goals / Non-Goals

Отменять новое изменение названия, сохраняя независимые правки и порядок изменений. Финансовые команды интегрируются отдельным change. Чтение и личный план остаются вне области изменения.

## Decisions

- Корневая строка ChangeLog содержит приватную версионированную команду. Дочерняя строка при необходимости ссылается на корень. Уникальная ссылка на отменённую строку защищает от повторного проведения.
- Закрытый реестр типизированных обработчиков выполняет обратную команду в транзакции caller. Повтор запроса сверяет устойчивое намерение по идентификатору результата. Отмена строки отката использует тот же обработчик.
- Версия названия увеличивается триггером только при фактической смене значения, даже если источник не изменяет клиентский код. Все штатные пути записи прикрепляют отдельную команду названия при изменении. Обратная команда использует тот же доменный update helper.
- Обработчик может вернуть ID сохранённых событий и пути кэша. Доставка выполняется после commit.
- Директор получает чтение глобального журнала и журналов изделий/проектов. Права записи повторно проверяются по активной записи пользователя.

## Risks / Trade-offs

- После любой более поздней правки названия старая операция конфликтует, даже если значение совпало после нового отката.
- Наследуемые строки остаются читаемыми. Исполнение требует сохранённой версии команды.
