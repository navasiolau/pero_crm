# Design

## Decisions

Общая ссылка принимает адрес и доступное название. Карточка изделия передаёт результат существующего расчёта возврата. Остальные экраны передают адрес родительского раздела, который работает и при входе по прямой ссылке.

Стрелка и заголовок — соседние элементы. Фон при наведении и обводка клавиатурного фокуса принадлежат ссылке. На узком экране заголовок переносится, а действия реестра при необходимости занимают следующую строку.
