# Proposal

## Why

Боковой редактор дублирует создание КП и просмотр сохранённых КП.

## What Changes

- Один набор навигации редактора; задача 204, согласована владельцем 31.10.2026.
- Система SHALL предлагать создание в рабочем разделе и выбор редакций сверху, сохраняя автосохранение и выбор приложений договора.

## Capabilities

### New Capabilities

- `kp-editor-navigation-cleanup`: Один набор навигации редактора.

### Modified Capabilities

Нет опубликованной основной спецификации этой возможности; прежние change artifacts используются как контекст.

## Impact

Удалить старые элементы и зависимые обработчики без удаления общего providers списка документов для договора. DOM references защищены или удалены; автосохранение не зависит от старой панели.
