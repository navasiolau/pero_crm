# Design

## Context

Боковой редактор дублирует создание КП и просмотр сохранённых КП.

## Goals / Non-Goals

Goals: Один набор навигации редактора. Non-Goals: изменения других бизнес-процессов.

## Decisions

Удалить старые элементы и зависимые обработчики без удаления общего providers списка документов для договора. DOM references защищены или удалены; автосохранение не зависит от старой панели.

## Risks / Trade-offs

Гонки, повторы и ошибки проверяются целевыми тестами. Production-данные и опубликованные документы не меняются во время локальной реализации.
