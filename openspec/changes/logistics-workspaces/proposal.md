# Proposal

**Execution agreement:** Номер задачи 125, ветка feature/125 согласованы владельцем 10.10.2026; OpenSpec и реализация одобрены. Одна целевая локальная проверка, затем существующий полный CI без изменений и развёртывание на staging только через него; одна целевая staging-приёмка. Повторные полные ручные проверки не выполнять без конкретного сбоя. Production/main этим запуском не разрешены.

## Why

Снабженцу нужны общий табличный список отгрузок и вкладка каждого проекта с теми же рейсами, составом, ТТН и затратами. Общий рейс должен сохранять одну идентичность при работе из любого связанного проекта.

## What Changes

- Добавить пункт бокового меню «Логистика» и таблицу: одна строка — один рейс/отгрузка, включая все связанные проекты и файлы накладных.
- Добавить вкладку «Логистика» в проект; общий рейс отображается во всех участвующих проектах. Вкладка показывает бюджет доставки из КП, сумму действующих затрат и остаток/перерасход.
- Общая форма позволяет выбрать изделия/материалы, проекты, доли, общую стоимость, кассу и ТТН. В проекте явно различаются полная стоимость рейса и доля этого проекта.
- По прямому уточнению владельца расходы рейса записываются прямо в расходы связанных проектов по их долям. Настройка или выбор статьи не требуется; факт доставки показывает только активные логистические распределения этого проекта.
- `PROCUREMENT`, `ADMIN`, `DIRECTOR` получают создание/редактирование и документы. Чистые `MANAGER`, `ENGINEER`, `WORKER`, `MOUNTER` не видят пункт/вкладку и не получают данные прямым запросом.
- `ACCOUNTANT` получает режим просмотра/скачивания ТТН через общий раздел без расширения обычного доступа к технической карточке проекта и без логистических writes.
- ТТН с одной печатью обязательна для списания; документы со второй печатью добавляются позднее, сохраняя исходные файлы.

## Capabilities

### New Capabilities

- `logistics-workspaces`: общий реестр и проектная вкладка, форма рейса, бюджетная сводка, документы бухгалтера и видимость по ролям.

### Modified Capabilities

Нет. Сохранение состояния существующих списков проектов/изделий, инженерная видимость и текущие финансовые права не изменяются.

## Impact

Зависит от `logistics-trips-and-ttn` и `logistics-cash-allocation`. Навигация и auth route guards, `projects/[id]/page.tsx`, `ProjectTabs`/разрешённые tab URL, новый `/logistics`, общие формы и `DataTable`, проекции данных, защищённые ссылки ТТН. Используются текущие компоненты выбора, просмотра и подтверждения; дополнительная библиотека не требуется.
