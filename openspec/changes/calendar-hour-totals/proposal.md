# Proposal

## Why

Согласованная задача №107 показывает плановую нагрузку за выбранный день и месяц. После №106 минуты уже сохраняются; суммирование должно быть единым для календаря и будущей аналитики108.

## What Changes

- Общая агрегация личных записей по дате Europe/Moscow.
- Итоги указанных плановых часов за день и месяц, отдельно часы выполненных записей.
- Отменённые исключены, отсутствующая длительность обозначена количеством записей; полностью неизвестные часы не показываются как ноль.
- Общий компонент итогов, обновляемый вместе с существующим состоянием календаря.

## Capabilities

### New Capabilities
- `calendar-hour-totals`: общие итоги плановой длительности личного календаря.

### Modified Capabilities

Нет; основная библиотека не содержит календарной capability.

## Impact

Общий модуль агрегации, компонент итогов и PersonalCalendar. Миграций/новых прав/фактических таймеров нет. Staging по разрешению, main ожидает владельца.
