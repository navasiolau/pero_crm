# Proposal

## Why

Нижняя горизонтальная полоса теряется под длинными колонками. По прямому уточнению владельца нужен обычный браузерный скролл снизу рабочей области, доступный на длинной доске.

## What Changes

- Общая нижняя native полоса прокрутки, синхронная с доской; сохранение вертикальной прокрутки страницы, touch/тачпада/Shift+wheel. Верхняя панель, range-ползунок и отдельные кнопки удаляются. Применение в проектах, изделиях и изделиях проекта.
- Задача 75, ветка bugfix/75; область согласована владельцем 05.10.2026 в запросе реализации плана75–78.

## Capabilities

### New Capabilities

- `kanban-horizontal-navigation`: Обычная браузерная полоса снизу рабочей области всех трёх досок.

### Modified Capabilities

Нет изменений основных спецификаций; связанные действующие changes сохраняют свою историю.

## Impact

Три канбана и новый общий UI-компонент; БД и серверные операции не меняются.
