# Design

## Context

Все три доски имеют data-slot=kanban-scroll и overflow-x-auto, общий app shell уже min-w-0. Карточки используют отдельные draggable-компоненты; их слушатели не менять.

## Goals / Non-Goals

**Goals:** доступная горизонтальная навигация на длинной доске.
**Non-Goals:** новые статусы, персистентное положение прокрутки, изменение drag/drop.

## Decisions

KanbanScrollArea оборачивает текущие колонки. Закреплённая сверху панель содержит native range-полосу и две кнопки. Ползунок показывает позицию scrollLeft в диапазоне0–(scrollWidth−clientWidth). Изменения доски обновляют только отображение ползунка; пользовательский input перемещает доску. Такая связь исключает отложенные взаимные scroll-events и отмену smooth scroll. ResizeObserver следит за контейнером/содержимым; MutationObserver не нужен. Шаг кнопки — ширина первой колонки плюс gap. Прокрутка по клавиатуре доступна фокусируемой области и кнопкам; горизонтальный wheel и touch остаются native. Панель скрывается при отсутствии overflow. Home/End и ползунок явно используют instant scroll; стрелки на колонку сохраняют smooth с учётом reduced-motion. Оставить существующий DragOverlay вне скролл-контейнера.

## Risks / Trade-offs

Sticky при внешнем overflow → сохранить локальный горизонтальный overflow только у доски, не у sticky-родителя. Длинная доска → браузерная проверка панели при вертикальном scroll. Resize/фильтры → clamp native и обновление размеров.
