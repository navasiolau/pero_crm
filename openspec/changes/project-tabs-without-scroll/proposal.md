# Proposal

## Why

Панель вкладок проекта включает горизонтальную прокрутку даже когда обычный набор вкладок можно расположить в доступной ширине. Полоса прокрутки и её стрелки затрудняют выбор последней вкладки «Журнал».

## What Changes

- Убрать горизонтальную прокрутку именно из панели вкладок проекта.
- Разместить обычный набор вкладок одной строкой при достаточной ширине; при узком экране или длинных названиях модулей переносить кнопки без обрезания и без горизонтального скролла.
- Сохранить порядок вкладок, последнюю позицию «Журнал», права доступа и управление клавиатурой.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `mobile-crm-usability`: исключить вкладки проекта из требования локальной горизонтальной прокрутки; их кнопки доступны целиком в адаптивной панели.

## Impact

Затронуты только `apps/web/src/components/project-tabs.tsx`, композиция вкладок страницы проекта и профильная браузерная проверка. Общие вкладки остальных страниц, серверные права, запросы, зависимости и схема БД сохраняются.
