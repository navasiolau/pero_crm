# Spec Delta

## MODIFIED Requirements

### Requirement: Полное состояние раздела сохраняется для пользователя

CRM SHALL сохранять поиск, текущие фильтры, сортировку и направление, вид, размер и номер страницы независимо для проектов и изделий текущего авторизованного пользователя. Наборы статусов и участников/клиентов/проектов SHALL храниться без срока действия для обоих разделов; только явное действие пользователя изменяет или сбрасывает их. Прежние одиночные значения и эффективные сохранённые настройки SHALL быть совместимы; смена options не очищает выбранные IDs автоматически.

#### Scenario: Возврат через меню
- **WHEN** сотрудник настроил список, открыл карточку или другой раздел и вернулся через меню
- **THEN** список и элементы управления восстанавливают сохранённые значения

#### Scenario: Повторный вход
- **WHEN** сотрудник повторно входит в CRM и открывает список без параметров
- **THEN** восстанавливается его последнее сохранённое состояние этого раздела

#### Scenario: Независимость пользователей и разделов
- **WHEN** второй сотрудник открывает список либо первый сотрудник переключается между проектами и изделиями
- **THEN** состояние другого сотрудника или раздела не применяется

#### Scenario: Долговременный множественный выбор
- **WHEN** после выбора нескольких значений проходят время, reload и повторный вход
- **THEN** сохраняется тот же набор, без TTL или самостоятельного сброса

#### Scenario: Быстрые изменения
- **WHEN** пользователь быстро меняет несколько чекбоксов либо options временно не содержит выбранный ID
- **THEN** поздний ответ не отменяет последний выбор и сохранённый ID не удаляется автоматически
