# Proposal

## Why

Владелец04.10.2026 требует несколько статусов/клиентов/менеджеров/инженеров одновременно на странице Проекты и сохранение выбора до ручного изменения. Однозначные селекты и неявный activeOnly=true этого не обеспечивают.

## What Changes

- Четыре выпадающих списка с чекбоксами и множественным выбором; меню остаются открытыми при выборе. Одна кнопка «Сброс» в меню очищает только этот фильтр. Пустой выбор и выбор всех пунктов означают отсутствие фильтра; искусственного состояния пустой доски нет.
- Переименовать галочку в «Незавершённые»; новые/сброшенные настройки по умолчанию показывают все доступные проекты.
- Сохранять выбор без срока действия в существующей UserPreference текущего аккаунта; возврат, reload, повторный вход и быстрые действия не сбрасывают его.
- Совместить multi-value состояние с прежними одиночными URL/настройками, сохранить авторизацию, CAS и независимость раздела Изделия.

## Capabilities

### New Capabilities

- `project-multi-select-filters`: множественные фильтры проектов с отдельными состояниями все/ничего/набор.

### Modified Capabilities

- `persistent-list-state`: сохранение массивов фильтров проектов и совместимость существующих предпочтений без expiry/самопроизвольного сброса.

## Impact

Project filter bar, checkbox dropdown, shared query codec/preferences и projects query/tests. Продолжение согласованной задачи3 из CRM_IMPROVEMENTS_PLAN.md; feature/3 от origin/staging221eaeec, отдельный OpenSpec. Без SQL миграции, новых сервисов и изменения ролевой видимости. Независимая корректировка прихода61 интегрируется отдельно.
