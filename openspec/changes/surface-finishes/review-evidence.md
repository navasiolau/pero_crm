## Исправления после review

- Короткое имя unique index согласовано между Prisma и SQL. Нормализованный ключ поверхности допускает расширение Unicode при uppercase, сохраняя лимит видимой подписи 80 символов; проверен пример `ß` × 80.
- Форма и подтверждение удаления запоминают product/revision/draftVersion при открытии. Обновлённые props не подменяют версию старой формы. При неизвестном результате старая форма закрывается, карточка обновляется, автоматического повтора записи нет.
- Дополнительный assertion-level RED показал, что payload мог перезаписать зафиксированные идентификаторы/версию при объединении объектов (3 PASS / 1 FAIL). Порядок объединения исправлен; 4/4 binding tests PASS.
- Образец HEX не сопровождается сообщением об отсутствии образца. Названия и коды сохраняют `№` и `²`; цвет не выводится из кода. Полное изображение открывается через защищённый маршрут, миниатюра — через существующий `?thumb=1`.
- Старый чистый тест staging-сессий однажды упал из-за границы секунды между двумя обращениями Auth.js к часам при создании `iat`/`exp`. Воспроизведён `SESSION_TTL_INVALID` при смещении только `Date.now` на секунду. В **тесте** зафиксированы обе формы часов через Node MockTimers; исполняемый session bridge, точная проверка TTL 900 и транспорт не изменялись.
