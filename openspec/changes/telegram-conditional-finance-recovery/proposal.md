# Proposal

## Why

Отдельная команда проверки утяжеляет список операций. Сохранённое подтверждение нужно только при неопределённом ответе CRM.

## What Changes

- Удалить команду проверки и её алиасы.
- Предлагать повтор сохранения только для операции, ожидающей подтверждения.

## Capabilities

### New Capabilities

- `telegram-conditional-finance-recovery` — восстановление сохранения в контексте операции.

### Modified Capabilities

## Impact

Нативный чат Telegram, подсказки и сценарии повторного подтверждения.
