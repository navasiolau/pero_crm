# Design

## Context

См. proposal.md. SQL защищает завершения/доли от изменения, FK исходной PayrollEntry уникальна. Существующая FIFO/CAS/UUID очередь полей сохраняется.

## Goals / Non-Goals

**Goals:** согласованный расчёт, атомарные добавочные корректировки и native-проверка ограничений.
**Non-Goals:** перенос начисленной оплаты другому исполнителю, новые правила цены/ставок, изменение доступов задачи91.

## Decisions

- ProductPercentageAdjustment хранит исходную долю/получателя, автора, UUID, ревизию, вид этапа, цену, количество, ставку, предыдущую/новую сумму и дельту. Исходные SETTLED данные неизменны. Миграция добавляет отдельную уникальную FK PayrollEntry; SQL защищает корректировки от изменения/удаления.
- Корректировки используют v4 и текущую подтверждённую цену/количество. Предыдущая сумма = последняя корректировка либо исходная доля; клиент использует ту же формулу. Старый нетронутый снимок сохраняет собственную версию.
- Конфиг/корректировка/PayrollEntry/receipt пишутся в общей транзакции с существующим lock/CAS. Ошибка после первой записи выбрасывается наружу для rollback. Уведомление вызывается после commit.
- Серверное чтение материализует исходную сумму + дельты. Экономика проекта суммирует исходные завершения и корректировки отдельно, исключая связанные PayrollEntry.
- SQL расширяет freeze-guards только однонаправленным заполнением неоплаченного SKIPPED_ONCE и его пустой доли; SETTLED/LEGACY остаются неизменными.
- Для ручного ввода превью сохраняет последний валидный draft; расчёт не зависит от подтверждения списка сотрудников. Денежное начисление по-прежнему валидирует получателя.

## Risks / Trade-offs

Уникальность/SQL-триггеры не воспроизводятся заглушками → native PostgreSQL тест всех денежных веток и rollback с fingerprint.
Повтор после потерянного ответа → прежний UUID/receipt, единственная корректировка на ревизию.

## Migration Plan

Добавочная forward-only миграция на существующем local/staging без дампов. Исторические денежные записи не переписываются. Производственный выпуск требует отдельного указания владельца.
