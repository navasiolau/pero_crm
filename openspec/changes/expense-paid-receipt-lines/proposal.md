# Proposal

## Why

Проведённый расход нужно связать с физическим поступлением материалов и провести по складу с сохранением исходной оплаты.

## What Changes

- В карточке обычного расхода доступно оприходование всего чека на одну или несколько позиций.
- Для проектного расхода предпросмотр явно показывает снятие назначения. Операция обратима через журнал при сохранности зависимостей.

## Capabilities

### New Capabilities

- `expense-paid-receipt-lines` ведёт поступление материалов по проведённому расходу.

### Modified Capabilities

## Impact

Финансовый журнал, складской учёт, кассовый отчёт и журнал отмены.
