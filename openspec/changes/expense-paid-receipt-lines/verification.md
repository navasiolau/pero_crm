# Проверка

- Prisma Client с объединённой схемой #240, #241 и #246 сгенерирован. TypeScript `tsc --noEmit --incremental false` завершился успешно.
- OpenSpec strict, целевые тесты распределения, запроса списка, привязки документов и журнала прошли.
- В Chromium на 390 px проверены выбор двух материалов, предпросмотр снятия с проекта, отсутствие отправки до подтверждения и отправка ровно двух строк. На 1440 px остаётся проверка реестра и фильтров. Подмена браузерных server actions действует только внутри фикстуры.
- Регрессии штатной оплаченной закупки, добавления материала и складской выдачи проверены отдельными компонентными сценариями.
- Сценарий PostgreSQL добавлен в существующую охраняемую CI-фикстуру. Локальная БД не использовалась. CI и фактическая staging-приёмка остаются на этапе интеграции.
- Предварительный общий прогон до объединения #241 и до переноса новой серверной границы из общего компонента в реестр расходов завершился с ошибками. Затронутые браузерные проверки повторены после исправления.
