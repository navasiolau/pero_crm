# Proposal

## Why

Сохранение КП одновременно меняет редакцию, проект, позиции, цены и управляемые медиа. Откат должен вернуть согласованное состояние одной транзакцией.

## What Changes

- Ссылаться на точную неизменяемую версию прежней редакции. Если выпуска этой редакции ещё не было, сохранить контрольную версию.
- Проверять текущие данные проекта, позиций и зависимостей перед отменой.
- Записывать обратное состояние в журнале с новой ревизией КП.

Версии КП, сохранение, связанные проект и изделия, журнал действий.
