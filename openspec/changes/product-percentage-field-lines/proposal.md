# Proposal: поле видит проценты строками, суммы только свои

## Контекст

После `bugfix/86` суммы у поля корректны, но вёрстка карточек для поля выглядит сломанной: скрытое поле `%` оставляет пустое место слева, disabled-селекты специалистов сбивают с толку (скрин приёмки 202.1). Владелец просит для поля вместо карточек простые строки.

## Цель

Для ролей без полного финансового обзора (`!canViewAll`: WORKER/MOUNTER/ENGINEER без менеджерской роли) карточка изделия показывает по каждому этапу одну текстовую строку «Роль: ФИО», и в той же строке «Оплата: сумма BYN» — только если этап назначен самому смотрящему (своя позиция; при комбинированных ролях — по каждой своей позиции). Неназначенные и чужие этапы — только имя назначенного (или «Не назначен»), без сумм вообще. Ни `%`, ни селектов, ни инпутов поле не видит. Вид менеджеров и снабжения (`canViewAll`) не меняется.

Уточнение правила прогнозов: прогноз неназначенного DRAFT остаётся видимым только менеджерам; поле без назначения на этап не видит никаких сумм (сценарий «DRAFT без назначенного для поля → 50 BYN» из `product-percentage-visibility` отменяется этим change).

## Non-goals

- Порядок секций страницы (строки инженера → файлы инженера → сборщик → монтажник) не меняется; сами файлы не трогаем.
- Формула, триггеры, начисление, серверные права — без изменений, кроме `total` для поля.
