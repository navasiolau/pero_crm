# Spec Delta

## Purpose

Текстовые строки процентных этапов для поля; суммы только по собственным назначениям.

## ADDED Requirements

### Requirement: Строки этапов для поля вместо карточек

При `!canViewAll` панель процентов SHALL рендерить по каждому этапу (Инженер/Сборщик/Монтажник) одну строку «Роль: ФИО назначенного», и в той же строке «Оплата: сумма BYN» — если этап назначен самому смотрящему. Ни `%`-полей, ни селектов, ни кнопок панель поля SHALL NOT содержать. Имена назначенных видны всегда («Не назначен», если пусто).

#### Scenario: Своя и чужая строки сборщика

- **WHEN** сборщик открывает изделие, где он назначен на ASSEMBLY (152 BYN), а на INSTALLATION назначен другой
- **THEN** строка сборщика «Сборщик: <он> Оплата: 152 BYN», строка монтажника — только имя, без суммы и без `%`

#### Scenario: Неназначенное изделие без сумм

- **WHEN** поле открывает изделие, где оно никуда не назначено
- **THEN** все три строки показывают только имена («Не назначен» где пусто), сумм нет вообще

#### Scenario: Комбинированные роли

- **WHEN** пользователь назначен и сборщиком, и монтажником одного изделия
- **THEN** обе его строки показывают его суммы

#### Scenario: Менеджер без изменений

- **WHEN** `canViewAll` открывает карточку
- **THEN** прежние карточки с `%`, селектами, суммами и прогнозами как раньше

### Requirement: Сервер не отдаёт полю прогноз неназначенного

`total` секции для не-`financeView` SHALL быть суммой своей строки при назначении, иначе null (прогноз `draftTotal` для поля отменяется; менеджерам отдаётся как раньше).
