# Proposal

## Why

Владелец согласовал красные названия всех файлов в группах вложений изделия. Явная настройка должна сохраняться у имени файла в просмотрщике, открытом из изделия, и не менять остальные экраны CRM.

## What Changes

- Имена картинок и документов в разделах вложений изделия получают читаемый красный цвет в светлой и тёмной темах.
- Настройка цвета передаётся явно в общий список и просмотрщик, включая содержимое portal.
- Сохраняются перенос длинных имён, исходные файлы, открытие, скачивание, печать и удаление.
- Полноэкранный просмотр изображений сохраняет текущую раскладку без дополнительной панели; видимые заголовки других форматов получают тот же цвет.
- Проектные файлы, финансы, логистика и задачи сохраняют прежнее оформление.

## Capabilities

### New Capabilities

- `product-file-name-color`: единое красное оформление видимых имён файлов только в изделии и открытом из него просмотрщике.

### Modified Capabilities

Нет: в основных specs отсутствует capability оформления имён файлов.

## Impact

Задача №177, ветка `feature/177`, основа — принятый код №176 из `origin/staging` (`e8886cc3`). Изменяются необязательные typed props общих компонентов списка/просмотрщика и адаптеров вложений изделия. API, БД, файловые маршруты и зависимости не меняются. Проверка — существующий browser-сценарий файлов на реальных компонентах с синтетическим транспортом; staging-приёмка отдельно у оркестратора.
