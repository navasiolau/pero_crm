# Design

## Context

Мотивация — в `proposal.md`. Разделы `ProductMeasurement` и `ProductDocuments` передают файлы через `FileGridView` в `FileList`; прежний `FilesTab` также умеет выводить группы изделия. `FileListRow` показывает изображение кнопкой и остальные форматы ссылкой скачивания. `FileViewer` рендерится через Dialog portal; его видимая панель имени используется документами/видео, а полноэкранные изображения показываются без имени.

## Goals / Non-Goals

**Goals:** явно передать цвет только имени через существующие общие компоненты и сохранить действия/доступ/геометрию.

**Non-Goals:** глобальные CSS-правила, новые метаданные, изменение dispatch файлов или панели полноэкранных фотографий, изменения данных и маршрутов.

## Decisions

- Необязательный typed prop `filenameTone: "default" | "red"` проходит от адаптера изделия через `FileGridView` / `FileList` / `FileListRow` к `useFileViewer` / `FileViewer`. Default сохраняет прежний стиль; явный prop проходит portal и не зависит от DOM-предка.
- Красный использует существующую палитру Tailwind `text-red-600 dark:text-red-400`, отдельно от состояния удаления. Класс применяется только к имени, не к кнопкам печати/удаления и не к целому контейнеру.
- Все product-группы задают `red`, включая ветку `FilesTab` с `productId`. Эскиз и канбан не показывают имя в полноэкранном просмотре, поэтому им не добавляется панель и их компоненты не меняются.
- Расширить существующий `file-list-printing.test.ts`: реальные адаптеры групп изделия, общий список для контроля изоляции, видимый заголовок viewer через hook/portal, три viewport, обе темы и длинные имена. Его существующие проверки защищённых оригиналов, печати и подтверждения удаления сохраняются. Серверные actions и Next-навигация заменяются закрытым синтетическим транспортом.

## Risks / Trade-offs

- Цвет может теряться в portal → передавать prop в сам viewer и проверять computed style заголовка.
- Общие компоненты используются вне изделия → default неизменен, браузер сравнивает одновременно product и обычный список.
- Длинное имя может вытеснять действия на телефоне → сохранить `min-w-0` / `break-all` и проверить overflow и клавиатуру на 390/360.

## Migration Plan

Миграции нет. Локальные проверки и независимое ревью предшествуют обычной интеграции в staging и приёмке развёрнутой ревизии оркестратором. Откат цвета не затрагивает файлы и БД.
