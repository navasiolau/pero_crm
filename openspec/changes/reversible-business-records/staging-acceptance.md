## Защита данных

Web подключён к staging под `pero_crm_staging_runtime`. Проверка полномочий базы вернула ноль нарушений. Для соединения приложения отдельно подтверждено отсутствие DELETE на изделии и журнале. Секрет мигратора недоступен UID 1000 приложения, Linux capabilities у процесса отсутствуют. Сохранились идентификатор существующего контейнера PostgreSQL, его том и действующий внешний сценарий W07.

На исходном дереве этой сборки инвентаризация нашла 174 экспорта HTTP и Server Actions в 72 модулях. Проверка вызовов Prisma и SQL в прикладном коде прошла. Реестр содержит 54 уникальные пары типа и версии обработчика отката. Для повторного включения отозванных секретов и Telegram-привязки требуется новое подтверждение. Журнал до внедрения доступен для чтения. Личный план исключён из общего аудита.

До раскатки проверена очередь старых заданий хранения. На исходной ревизии ожидали 454 задания КП, действующих аренд удаления файлов и очистки КП не было. После раскатки очередь продолжила штатную обработку с защитой опубликованной истории. При контрольном чтении ждали 174 задания, действующих аренд очистки также не было.

## Telegram

Проверен отдельный процесс бота на указанном digest. Контрольная неподтверждённая операция пережила замену контейнера с исходным UUID. Квитанция повторной команды очистила её. На опубликованном коде в контейнере прошли 16 тестов финансового диалога и документов с изолированным транспортом. В них проверены неоднозначный выбор проекта, дата, ручной курс, вложения и повтор после потери подтверждения.

Страница входа Mini App отдала 200 по HTTPS и загрузила официальный Telegram SDK. Она корректно предложила открыть личный чат в браузере без идентификации Telegram. Пустой запрос, запрос без удостоверения Telegram и подтверждение без начатой привязки получили 400, 403 и 409. Финансовая страница без пользовательского сеанса перенаправила на вход.

Для завершения приёмки в реальном клиенте требуется разрешённая тестовая учётная запись Telegram. Запуск кнопкой «Финансы», привязка и открытие вложения внутри настоящего WebView остаются отдельным пунктом.
