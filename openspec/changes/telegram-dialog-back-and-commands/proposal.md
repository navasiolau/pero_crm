# Proposal

## Why

Кнопка отмены в чате сбрасывает весь ввод, в том числе при отмене ручной даты. Часть команд и кнопки с тестовыми названиями затрудняют навигацию.

## What Changes

- Назад возвращает к последнему шагу черновика и сохраняет введённые до него данные.
- Полная отмена вводится отдельной кнопкой. Неопределённый результат денежной операции проверяется по прежнему идентификатору.
- Подсказки используют понятные русские команды. Старые команды продолжают выполнять те же действия.
- Бот скрывает кнопки с названием «Тест».

## Capabilities

### New Capabilities

- `telegram-dialog-back-and-commands` — навигация по шагам чата и понятный список команд.

### Modified Capabilities

## Impact

Чат Telegram и его сценарии. Используются прежние серверные операции CRM.
