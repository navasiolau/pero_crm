# Spec Delta

## Purpose

Сохранять работу пользователя в пошаговых диалогах Telegram и делать команды и кнопки понятными.

## ADDED Requirements

### Requirement: Возврат на предыдущий шаг

Диалог Telegram SHALL отделять возврат на шаг от отмены всей операции. При неопределённом денежном результате система SHALL сохранять исходную команду и её идентификатор.

#### Scenario: Ручная дата оплаты

- **WHEN** пользователь открывает ввод даты прихода и нажимает «Назад»
- **THEN** бот возвращает меню проверки прихода с сохранёнными суммой, кассой, комментарием и датой

#### Scenario: Складской черновик

- **WHEN** пользователь возвращается с шага количества к выбору материала либо исходной выдачи
- **THEN** предыдущий выбор проекта или изделия сохраняется

### Requirement: Понятные команды и варианты

Бот SHALL показывать понятные названия команд, поддерживать прежние алиасы и исключать кнопки «Тест» из выдачи.

#### Scenario: Справка и выбор кассы

- **WHEN** пользователь открывает список команд или выбор из справочника
- **THEN** он видит понятное название операции и рабочие варианты без кнопок «Тест»
