# Проверка

Сборка и 51 тест бота прошли. Проверен возврат из ввода неверной ручной даты к сводке с прежней датой, суммой, кассой и комментарием. Старая кнопка сводки отклоняется, действующая проводит операцию один раз. Проверены возврат на склад с сохранением изделия и исходной выдачи, полная отмена по отдельной кнопке, алиасы команд и скрытие варианта «Тест».

При потере ответа возврат по шагам сохраняет ожидающую проверки денежную операцию. Команда проверки повторяет запрос с прежним идентификатором после перезапуска.

При staging-приёмке сверить SHA образа, здоровье бота, сохранение тома финансовых подтверждений и наличие новых команд и кнопок в опубликованном артефакте.
