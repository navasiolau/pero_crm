# PERO NAS — корпоративное файловое хранилище (руководство сотрудника)

NAS — общий диск компании для рабочих файлов: фотографии, видео, документы.
Хранится на сервере компании на зеркальном (RAID1) зашифрованном массиве.
Доступ — только из офисной сети или через NetBird (дома/в дороге).

**Два способа работы — выбирайте удобный (можно оба):**

| Способ | Адрес | Для чего |
|---|---|---|
| Сетевой диск (SMB) | `\\192.168.0.32\nas` | постоянный диск «N:» на компьютере, работа как с обычной папкой (только офисная сеть / NetBird) |
| Веб-интерфейс | `https://files.peromebel.by` | из браузера откуда угодно: посмотреть, скачать, загрузить с телефона/чужого ПК |

Логин и пароль — индивидуальные, выдаёт администратор (см. файл учётных записей
у владельца). Один и тот же логин работает и на сетевом диске, и в браузере.

## 1. Сетевой диск на Windows

1. Откройте «Этот компьютер» → вкладка «Компьютер» → **«Подключить сетевой диск»**.
2. Диск: любая свободная буква (например `N:`).
3. Папка: `\\192.168.0.32\nas`.
4. Галочки: ✅ «Восстанавливать подключение при входе в систему».
5. Нажмите «Готово» → появится окно входа:
   - Пользователь: **ваш логин NAS** (например `rsubotka`)
   - Пароль: ваш пароль NAS
   - ✅ «Запомнить учётные данные»
6. Готово — диск откроется как обычная папка. Копируйте файлы перетаскиванием.

Если окно входа не появилось, а диск не открылся: панель управления →
«Диспетчер учётных данных» → «Учётные данные Windows» → «Добавить учётные
данные Windows» → адрес `192.168.0.32`, ваш логин/пароль → повторить шаги.

**Смена пароля NAS** (после сброса администратором): сначала отключите диск
(правой кнопкой → «Отключить»), подключите заново, введите новый пароль.

## 2. Сетевой диск на Arch Linux (и другие дистрибутивы)

Пакеты: `sudo pacman -S cifs-utils` (или `smbclient` для разового доступа).

**Разовое подключение:**
```bash
sudo mkdir -p /mnt/nas
sudo mount -t cifs //192.168.0.32/nas /mnt/nas \
  -o username=ВАШ_ЛОГИН,uid=$(id -u),gid=$(id -g),iocharset=utf8,vers=3.0
```

**Постоянный диск при загрузке** — пароль в отдельный файл (только для вас):
```bash
mkdir -p ~/.smbcredentials
cat > ~/.smbcredentials <<'EOF'
username=ВАШ_ЛОГИН
password=ВАШ_ПАРОЛЬ
EOF
chmod 600 ~/.smbcredentials
```
Строка в `/etc/fstab`:
```
//192.168.0.32/nas  /mnt/nas  cifs  credentials=/home/ВАШ_ЮЗЕР/.smbcredentials,uid=1000,gid=1000,iocharset=utf8,vers=3.0,_netdev,nofail  0  0
```
Проверка: `sudo mount /mnt/nas`. Диск появится в файловом менеджере.

## 3. Веб-интерфейс (Filebrowser)

1. Откройте **`https://files.peromebel.by`** (работает из любой сети, вход по вашему логину/паролю NAS).
2. Войдите вашим логином/паролем NAS.
3. Возможности:
   - **Загрузка**: кнопка ⬆ или перетащите файлы в окно браузера
   - **Скачивание**: клик по файлу → «Скачать» (или ПКМ → скачать)
   - **Папки**: создание, переименование, перемещение (кнопки сверху)
   - **Просмотр**: фото/видео/текст открываются прямо в браузере
   - **Ссылка на файл**: выделите файл → «Share» → получите ссылку для коллеги
   - **Множественный выбор**: Ctrl+клик по файлам → массовые действия
4. Смена своего пароля: «Settings» → «User Settings» → «Change password».

## Правила и ограничения

- Общее пространство на всех: **1 ТБ** — не используйте NAS как личный архив,
  тяжёлые личные файлы храните локально.
- Не удаляйте и не переименовывайте чужие файлы без согласования.
- Конфиденциальное (зарплатные ведомости, персональные данные клиентов) —
  в NAS не хранить; для этого есть CRM с разграничением прав.
- Резервное копирование NAS выполняется автоматически (ежедневно) — но удалённый
  файл восстановим только в пределах суточной копии, будьте внимательны.
- Доступ из дома/дороги — через NetBird (подключить у администратора).
