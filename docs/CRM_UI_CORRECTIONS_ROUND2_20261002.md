№32 остаётся отдельным production-отчётом `NON_BYN_PROJECT_PRICES.xlsx`. Его источник — актуальные данные CRM через прикладной доступ, без прямого чтения production-БД. Владелец вносит production-значения вручную. Новое указание разрешает фактический пересчёт существующих local и staging данных; прежнее ограничение «отчёт без записи» продолжает действовать для production.

Для пересчёта отбираются только проекты с текущей валютой не BYN. Курс НБ РБ берётся на календарную дату создания проекта в Europe/Moscow с учётом Cur_Scale. Цена за штуку округляется до копеек, затем умножается на отдельное количество. Проектные услуги и известные первоначальные цены указываются отдельно; null сохраняется. Сохранённые выплаты, завершения этапов, история и валюты физических касс не переименовываются и не переписываются.

Каждая ветка создана после fetch от origin/staging `02d7db19a78ac1ec30bc515e4a0a3e43e08dd01a`. Дампы, restic, seed/reset, обход финансовых ограничений и выпуск в main не входят в задачу. Ночной refresh staging и W07 сохраняются.
