# Чтение материалов проекта

Материалы нескольких изделий получает getProjectMaterialsBatch; getProjectMaterials делегирует ему с одним ID. Страница проекта загружает группы одним вызовом и использует прежний позиционный DTO. Пустой список возвращает [] без запросов; повторённые IDs сохраняют позиции.

Потребности, складское состояние, оценки выдач, авторы и документы читаются общими выборками. История ограничена последними 500 движениями **на каждое изделие** в порядке createdAt DESC / id DESC. INCOME исключается после этого ограничения. Финансовый итог считает всю активную EXPENSE/RETURN историю и сохраняет null для неизвестной стоимости.

Видимость истории отличается от видимости потребностей. Существующий grant ADMIN/DIRECTOR сохраняет активные движения удалённого изделия/проекта. Потребности, оценки и итоги при этом сохраняют свой productVisibilityWhere. Для ENGINEER/PROCUREMENT административный обход не появляется. ACCOUNTANT без office роли по-прежнему не получает этот reader.

WAC, ready/phase, shortage/debt, archived material, исторический issuedQty и источники возврата используют прежние формулы. Reader не изменяет состояние склада, деньги, движения или настройки интерфейса. Миграций и новых зависимостей нет.

Unit memory model: точное сравнение с frozen cd38 reader, 1/5/20 изделий — 10/10/10 вызовов чтения после отдельного per-product SQL-порядка потребностей. Это не измерение реального PostgreSQL. Actual local PostgreSQL 6bcf6c6d: 1/5/20 изделий — 14/14/14 SQL-запросов, точный DTO/scalar и роли совпали с прежним reader, включая фикстуры с равными датами. Rollback подтвердил сохранность исходных данных и схемы; склад остался UNINITIALIZED, ACTIVE WAC этим запуском не доказан. Визуальная приёмка и staging ещё не выполнены.

Потребности сохраняют прежний createdAt ASC отдельно для изделия через один bounded LATERAL-запрос; mapper использует ordinal только для уже разрешённых строк. ID tie-sort не вводится. SQL не гарантирует универсальность порядка при равных датах, поэтому native приёмка требует точного совпадения с прежним reader.
